# External languages

This folder contains bundled UTF-8 language files (`<code>.json`).
For local overrides, use `<persistentDataPath>/QuickSave/Mods/DreamforgeRPG/lang/` and reload the MOD settings.
Select a loaded language with the language button or the `language` setting; untranslated text uses English.
Submit translations as a pull request to [`translations/` in Kling0012/dreamforge-rpg](https://github.com/Kling0012/dreamforge-rpg/tree/main/translations).
