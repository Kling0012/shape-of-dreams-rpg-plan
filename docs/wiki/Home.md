# Dreamforge RPG Wiki

Shape of Dreams 用 MOD「Dreamforge RPG」の導入と遊び方を案内します。遺物を持ち帰り、旅人ごとの星図を育て、次の遠征へ進みます。

A guide to installing and playing Dreamforge RPG for Shape of Dreams. Bring relics home, develop each traveler's Star Map, and prepare for the next expedition.

この案内は v3.8.4 の仕様を基準にしています。更新時は [Releases](https://github.com/Kling0012/shape-of-dreams-rpg-plan/releases) と [更新履歴 / Changelog](https://github.com/Kling0012/shape-of-dreams-rpg-plan/blob/dev/CHANGELOG.md) も確認してください。

## 装備と星の一覧 / Equipment and star catalogs

既存の一覧はゲームのデータと共通の説明処理を使う `tools/WikiGen` から作られています。[生成済みの装備・星図データ](https://github.com/Kling0012/shape-of-dreams-rpg-plan/tree/wiki-pages/pages/dreamforge) は DokuWiki 用の記法です。土台・固有品・セット・固有効果・特性と、旅人別の星の説明を参照できます。

The existing catalogs use game data and shared descriptions through `tools/WikiGen`. The generated equipment and Star Map data linked above uses DokuWiki markup and covers bases, uniques, sets, powers, affixes and each traveler's stars.

## 協力プレイと更新 / Co-op and updates

参加者全員が同じ MOD の版を使い、更新後はゲームを再起動してください。能力の反映にはホスト側にも MOD が必要です。

Everyone in co-op should use the same MOD version and restart the game after updating. The host also needs the MOD to apply its effects.
