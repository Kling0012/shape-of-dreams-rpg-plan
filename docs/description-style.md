# 説明文の書き方（装備・星図・図鑑）

装備の固有効果・セット効果・ボス装備、星図の星・刻印・連携の説明文は、コード（`Content.cs`、`Gimmicks*.cs`、`Links.cs`、
`StarMapPresentation*.cs`、`BossProfiles.*.cs` など）が `Loc.T(日本語, 英語)` で生成する。数値や効果そのものは変えず、
読み手が条件・対象・数値・時間を取り違えないことを最優先にしたうえで、**日本語として普通に読める文章**で書く。

日本語の説明文は箇条書き（「・」で行を分ける形）にしない。1つの効果は、1つの段落（1〜3文）の文章で書く。
英語の説明文は従来どおり、1行目の要点と「・」の項目に並べる（`EffectLayout.Bullets`）。

`tests/SodRpg.Core.Tests/CodexTextConsistencyTests.cs` が、生成された説明文（日本語・英語）に対して機械的な規則を検査する
（全角記号、内部ID、「です・ます」調、日英で数値と単位がそろっているか）。

## 規則

1. **記号は半角の `+` `-` `%` を使う。** 全角の `＋` `−` は使わない。ただし、本文では「+」「-」よりも「増える」「下がる」などの動詞を使う。
2. **文末は常体（である調・体言止め）。** ゲーム内の効果説明に「です」「ます」は使わない。
3. **単位を省かない。** 上限の数値には必ず `%`・`m`・`秒`・`つ` などの単位を付ける（`上限36` ではなく `上限36%`）。
4. **意味のない値を出さない。** 「0%の確率」「さらに0%」のような値は書かず、その節ごと省く。
5. **内部IDを出さない。** `Mon_…` `St_…` `Gem_…` `Se_…` ではなく、表示名を使う。
6. **属性の蓄積は「つ」で数える。** 火1つ、冷気2つ。「個」は欠片・アイテムなど物に使う。
7. **余計な空白を入れない。** 「 を」「。 」や連続した空白は使わない。
8. **確率・率は「%」で書く。** 「確率が15%上がる」「会心率が3%上がる」のように、足し算の意味で読めるときは「パーセントポイント」と書かない。
   元の値に掛ける割合は「ダメージが4.8%増える」のように書き分ける。
9. **ボス装備の段階は「固有報酬の段階N」と書く。** 単に「段階1」だけだと連携の段階と区別できない。
10. **重ならない効果は「重ならず」で書く。** 更新される場合は「時間が延びる」まで書く。

## 文章の組み立て

効果は次の順の文章にする。

1. **1文目：いつ、何が起きるか。** 条件→結果の順（「〜したとき、〜する」「〜している間、〜が増える」）。
2. **2文目以降：間隔・持続・重なり方・上限・例外。** 必要なものだけを短い文で続ける。
3. **文末の注記は括弧に入れる。** 段数・費用の注記（`数値は1段ごと。最大3段、1段につき1ポイント`）は最後に括弧書きで添える。
4. 1文が長くなったら、読点でつなぎ続けず文を分ける。「〜し、〜し、〜する」の連続は2回までにする。
5. 「効果名 +量：対象」の記号調（`障壁 +最大HPの8%：自分に張る`）や、体言止めの断片を並べた書き方は使わない。

```
最大HPの10%以上の一撃を受けたとき、最大HPの8%の障壁を6秒間得る。再発動まで12秒かかる。（数値は1段ごと。最大3段、1段につき1ポイント）
```

装備側の複数段の効果（セット効果・ボス装備）は、段ごとに「2つ装着：」のように見出しを置き、その後ろに1段落で書く。

## 言い回し（そろえる語）

| 内容 | 書き方 |
| --- | --- |
| 能力値の増減 | 「攻撃力・魔力が25%上がる」「与えるダメージが6%増える」「クールダウンが短くなる」 |
| 障壁 | 自分が受けるとき「障壁を得る」、相手に与えるとき「障壁を付与する」 |
| 回復 | 「最大HPの1%を回復する」 |
| 属性 | 「敵に光を1つ付ける」「冷気を付与する」 |
| 間隔 | 「再発動まで5秒」「0.15秒に1回まで」（効果ごとにどちらかに統一） |
| 上限 | 「最大40%まで」「合計で最大15%まで」 |
| 同じ効果の合算上限 | 「装備・星の同じ効果は合計で最大15%まで」 |
| 時間の上限 | 「合計で最大X秒まで」 |
| 重なり | 「重ならず、再発動すると時間が延びる」 |

## 用語

| 用語 | 使い方 |
| --- | --- |
| 装着 | 装備品・エッセンスを身に着ける |
| 装備中 | 記憶（スキル）を装備している状態（星図側の文） |
| 付与 | 属性・障壁・効果を相手に与える |
| 道標 | ゾーンのルール上の名称（Waypoint）。言い換えない |
| 固有報酬の段階 | ボス装備の任意報酬が持つ強化段階（1〜3） |
