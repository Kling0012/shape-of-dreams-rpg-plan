# 説明文の書き方（装備・星図）

装備の固有効果・セット効果・ボス装備、星図の星・刻印・連携の説明文は、コード（`Content.cs`、`Gimmicks*.cs`、`Links.cs`、
`StarMapPresentation*.cs`、`BossProfiles.*.cs` など）が `Loc.T(日本語, 英語)` で生成する。数値や効果そのものは変えず、
読み手が条件・対象・数値・時間を取り違えないことを優先する。

`tests/SodRpg.Core.Tests/DescriptionStyleTests.cs` が、生成されたすべての説明文（日本語・英語）に対して下記の機械的な規則を検査する。

## 規則

1. **記号は半角の `+` `-` `%` を使う。** 全角の `＋` `−` は使わない（`+3%`、`-50%`）。
2. **文末は常体（である調・体言止め）。** ゲーム内の効果説明に「です」「ます」は使わない。
3. **単位を省かない。** 上限の数値には必ず `%`・`m`・`秒`・`つ` などの単位を付ける（`上限36` ではなく `上限36%`）。
4. **意味のない値を出さない。** 「0%の確率」「さらに0%」のような値は書かず、その節ごと省く。
5. **内部IDを出さない。** `Mon_…` `St_…` `Gem_…` `Se_…` ではなく、表示名を使う。
6. **属性の蓄積は「つ」で数える。** 火1つ、冷気2つ。「個」は欠片・アイテムなど物に使う。
7. **余計な空白を入れない。** 「 を」「。 」や連続した空白は使わない。
8. **上限の書き方をそろえる。**
   - 装備と星の合算上限：`（装備・星の同じ効果は合計で最大X%）`
   - 星1つごとの上限：`効果量は最大X%`
   - 時間：`合計で最大X秒`
9. **ボス装備の段階は「固有報酬の段階N」と書く。** 単に「段階1」だけだと連携の段階と区別できない。
10. **重ならない効果は「重ならず」で書く。** 更新される場合は「時間を延長」まで書く。

## 箇条書き

画面に出す効果は、1行目に効果の要点、続けて条件・間隔・上限を「・」の箇条書きで並べる。コード上の説明文は1行のまま作り、
画面・図鑑・wikiに出すときに `EffectLayout.Bullets`（装備は `Content.FormatPowerBullets`、星は `StarMapPresentation.DisplayDescription`）で並べ替える。
集計・検索・書き出し用の1行の文は `Content.FormatPower` と `StarMapPresentation.EffectDescription` を使う。

```
障壁 +自分の最大HPの8%
・自分の技で敵をスタンさせたとき、自分へ3秒間付与
・2秒に1回
・装備・星の同じ効果は合計で最大15%
```

- 文（「。」）、「効果／条件」の「／」、文末の括弧書き、手順をつなぐ「、その0.4秒後に」「、さらに」は、それぞれ1項目にする。
- 文中の括弧（`ダメージ（上限36%）を与える`）は分けない。
- 段数・費用の注記（`数値は1段あたり…`）は括弧付きの1項目にする。

## 構成（一つの効果の書き方）

```
<効果名> +<量>：<対象・範囲>。<発動条件>（<間隔>・<上限>。<例外>）
```

- 効果名と量を先頭に置き、対象・範囲を `：` の後に続ける。
- 発動条件は文として書き、括弧にはクールダウン・上限・例外だけを入れる。
- 同じ内容の注意書きは、できるだけ1か所にまとめる（刻印の倍率の注記など）。

## 用語

| 用語 | 使い方 |
| --- | --- |
| 装着 | 装備品・エッセンスを身に着ける |
| 装備中 | 記憶（スキル）を装備している状態（星図側の文） |
| 付与 | 属性・障壁・効果を相手に与える |
| 道標 | ゾーンのルール上の名称（Waypoint）。言い換えない |
| 固有報酬の段階 | ボス装備の任意報酬が持つ強化段階（1〜3） |
