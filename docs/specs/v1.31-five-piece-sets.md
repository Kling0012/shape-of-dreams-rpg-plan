# v1.31 セットを5部位に（5つそろえたときの効果と、新しい部位）

利用者の要望（2026-10-04）：今あるセット装備を基に、5個の場合のセットを追加する。そのさいに必要な新装備も作る。

## いま
48組すべてが3部位（主装備・防具・装飾品）。効果は「2つ装着：能力値」「3つ装着：固有効果」。

## 決めたこと
- 各セットに**新しい部位を2つ**足して5部位にする。部位は頭・手・足のうち、セットの雰囲気と系統に合う2つ。土台は今ある土台（同じ枠・同じ系統）から選ぶ。新しいアイコンは作らない。
- 新しい部位は、ほかのセット品と同じく固有品（レジェンダリー）で、固有効果を2つ持つ。セットの3部位の固有効果と噛み合うものを選ぶ。
- **5つ装着の効果**を各セットに1つ。能力値を上げるだけにはせず、そのセットの戦い方が変わるものにする。使うのは、ゲームに届いていると確認済みの固有効果（docs/reviews/effect-wiring-audit.md）。値は控えめにし、3つ装着の効果に上乗せする。
- 4つ装着では新しい効果を付けない（2・3・5の3段階）。
- 既存の2つ・3つの効果は変えない。すでに持っているセット品はそのまま使える。
- 「持っているセットの足りない部位が出やすい」仕組みは、新しい部位にもそのまま効く。
- 画面（装備・図鑑）、Wiki、ホストの検証も5つの段階に対応させる。

## 守ること
- 攻撃力・魔力の％を上げる効果は、条件つきでも合計の上限（120%）を超えない。
- 回避で発動する効果は入れない。重なる効果は上限を書く。人名は使わない。
- 保存形式は変えない（新しい固有品の ID を足すだけ）。
