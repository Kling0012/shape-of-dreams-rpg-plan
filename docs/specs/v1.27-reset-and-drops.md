# v1.27「プロフィールのリセット」と「ドロップ率の引き下げ」

利用者の指示（2026-10-03）：固有品などのドロップ率も下げる。次は大規模変更なので、プレイヤーのデータや所持品を一度リセットする。

## リセット
- 保存の版（`Profile.CurrentVersion`）を 1 → 2 に上げる。
- 版1の保存を読んだときは、プロフィールを**新しく始める**（夢のレベル・所持品・素材・星図・図鑑・実績・統計をすべて初期状態に）。
- 前のデータは消さない：`profile.json` を `profile.v1-archive-<日時>.json` として同じフォルダに写してから始める（`.bak` も同様に写す）。
- 起動時の知らせ：「大きな更新のため、プロフィールを新しく始めました。前のデータは profile.v1-archive-… に残しています。」
- 版2の保存は今までどおり読む。版2より新しい保存は今までどおり読まない。
- 協力プレイ：各自のプロフィールは各自の PC にあるので、全員が v1.27 を入れた時点でそれぞれリセットされる。

## ドロップ率
BalanceSim（v1.22 の前提）では、1回の遠征で伝説（固有品）約0.27個・エピック約1.5個。覚醒の3段・限界突破・旅人ごとの大きな星図で長く遊ぶ前提に合わせて下げる。
- レア度の重み：コモン600・アンコモン270・レア100・エピック26・伝説3 → **エピック22・伝説1.5**（伝説は半分、エピックは約15%減）。
- 重みは整数なので、全体を2倍にして `1200, 540, 200, 44, 3` とする。
- エピックの天井（ボス撃破で上がる確率）、セットの重み、契約や夢の出来事による固有品の入手はそのまま。全体のバランス調整で BalanceSim を回して確かめる。

- 版1の保存を読むと新しいプロフィールになり、写しが残り、知らせが出る。版2はそのまま読める。
- 重みの比（伝説は前の半分、エピックは22/26）。
