# 属性の反応 / Element reactions

火・冷気・光・闇のうち、対応する2属性が敵にそろうと装備の反応が起きる。属性を付けた旅人がその反応を持っていることが条件で、通常攻撃だけに限定しない。味方が先に付けた属性も使える。属性のスタックは消費せず、元の冷気・光・闇の上限も変えない。

An equipped reaction activates when its owner applies an element to an enemy carrying the required pair. Existing elements from allies count. Basic attacks are not required, and native elemental stacks are never consumed or overwritten.

| 反応 / Reaction | 条件 / Pair | 効果 / Effect | 装備の合計上限 / Equipped cap |
| --- | --- | --- | --- |
| 蒸気 / Steam | 火＋冷気 / Fire + Cold | 対象と周囲3mに、攻撃力・魔力の高い方を基準とする無属性の爆発。30%のスロウを2秒付与 / Non-elemental burst using the higher of AD or AP, with a 30% slow for 2 seconds | ダメージ120% / 120% damage |
| 蝕 / Eclipse | 光＋闇 / Light + Dark | 4秒間、その旅人から受けるダメージが増える。同じ旅人の既存Exposeとは高い方だけ / Increased damage from that hero for 4 seconds; uses the higher existing Expose value | 25% |
| 燃え殻 / Cinder | 火＋闇 / Fire + Dark | 印を残し、死亡時に周囲4mへ火を1つ付与。味方の撃破でも有効 / A mark spreads 1 Fire stack within 4 metres on death, including ally kills | 火1つ。印は重ならない / 1 Fire stack; marks do not stack |
| 氷晶 / Frost Crystal | 光＋冷気 / Light + Cold | 自分に最大HPを基準とする障壁を4秒付与 / A shield based on the hero's maximum health for 4 seconds | 最大HPの12% / 12% maximum health |

## 間隔と既存の戦い方

同じ旅人の同じ反応は、同じ敵に6秒に1回。継続する属性や多段の記憶から爆発・障壁が無制限に連発することを防ぐため、この間隔を置く。敵ごと・反応ごとに独立し、4反応と四元の共鳴は共存する。装備情報の再送や付け直しで間隔を消さない。敵の死亡・消滅、旅人の解除時に状態を片付ける。

The 6-second interval is independent for each hero, enemy and reaction. It prevents persistent elements and repeated hits from generating unrestricted bursts or shields. Resending a build does not reset the interval. Death, despawn and hero detachment remove obsolete state.

ゾーン読み込み時とゾーン管理オブジェクトの切り替わりでは、反応の待ち行列・対象参照・間隔・印をすべて破棄する。前のゾーンで保存した爆発の中心座標を新しいゾーンへ持ち越さない。装備情報の再送では破棄しない。

Zone loading and replacement of the zone manager discard pending reactions, target references, intervals and marks. Captured burst positions cannot carry over and hit entities in the next zone. Build resends do not perform this reset.

自動で攻撃する記憶、火や冷気を維持する記憶、HPを捧げる記憶にも、通常攻撃・高HPの条件を加えない。移動や向きを変更せず、スロウは既存の強いスロウを弱めない。障壁は旅人からの支援通知を出さない経路を使い、本体の支援条件を勝手に回さない。

Reaction bursts use the v1.28 gimmick isolation marker and synchronous guard. The existing final received-damage patch removes elemental attributes and attack procs after native processors. Bursts cannot re-amplify Expose or memory bonuses, trigger memory gimmicks, or trigger death powers and Cinder. Cinder's immediate Fire application cannot trigger another reaction, Convergence or Wildfire. Added Fire then remains an ordinary native elemental stack; its native lifetime and shared stack behavior are preserved.

## 仕様の補足 / Implementation decisions

- 道標の反応倍率は、蒸気のダメージ・蝕の増幅率・燃え殻の付与数・氷晶の障壁量に掛ける。装備の上限を適用してから掛ける。範囲・持続時間・30%のスロウ・6秒の間隔は変えない。 / The waypoint multiplier affects amounts after equipped caps, without changing control strength, radii, durations or the interval.
- 印は重ならず、その敵の生存中は残る。とどめを刺した旅人と印を付けた旅人は別でもよい。 / Cinder persists for the target's lifetime and is owned by the marking hero, independently of the killing hero.
- 蒸気と氷晶の実作用は次のホスト更新へ送る。元の命中が終わる前に追加ダメージがとどめの出どころを変えない。 / Native burst and shield dispatch is deferred until the next host update to preserve original hit attribution.
- 装飾品には4反応、頭には蝕・氷晶、手には蒸気・燃え殻を追加。エピックは既存の枠別固有効果プールから選ぶ方式を保つ。レアも同じプールの弱い値を使う既存の仕組みは変更しない。 / Charm offers all four; Head offers Eclipse and Frost Crystal; Hands offer Steam and Cinder. The existing shared pool and weaker Rare-power behavior are retained.
- 保存と装備通信は、末尾に追加したPower IDと既存Buildの符号化を使用。反応の一時状態は保存しない。 / Appended power IDs use the existing build encoding; temporary combat state is not persisted.

Coreで全属性の組み合わせ、スタック不変、間隔の境界と独立性、再送、孤立した効果の抑止、印とExposeの寿命、倍率・上限、装備通信、両言語の説明を検証した。本体APIは宣言・逆コンパイル・Modビルドによる確認で、Unity内の実戦確認は未実施。

Core validation covers all elemental combinations, unchanged snapshots, exact independent intervals, resends, isolation, mark and Expose lifetimes, multipliers and caps, build encoding and bilingual text. Native behavior has been checked against declarations and decompiled code; live Unity combat has not been exercised.
