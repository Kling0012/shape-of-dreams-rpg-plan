## 星の表記と展開規則

新規星はすべて1段。`D(m,v)`=MemoryDamage、その記憶の本体ダメージ+v%。`H(m,v)`=MemoryHaste、その記憶だけのクールダウン補正v%。`B(m,v)`=GimmickBoost、その記憶の有効な仕掛け値+v%。`P(m,id,Duration,v)` / `Radius` は指定した仕掛けの時間 / 半径+v%。本体の持続時間、無敵、バインド、投射物には作用しない。

`G(m,tr,e,v,a,c)` は **Notableの完全なGimmickDef**：Memory=m、Trigger=tr、Effect=e、Value=v、Arg=a、Cooldown=c。`hit/use/kill` は `OnHit/OnUse/OnKill`。表で `a,c` を省略した場合は必ず `0,0`。値は%（Elementのみ100で1スタック、余りは追加1スタックの確率）。例：`G(E,hit,Echo,8)` は `(OnHit,Echo,8,0,0)`。

`RC(s,t,tr,v)` は新規Notable `DirectedRecharge`：SourceMemory=s、TargetMemory=t、Trigger=tr、Value=v、Arg=0、Cooldown=0。tの**残り**クールダウンをv%短縮。受け手以外の記憶には作用しない。`RW(T,q,v)` は新規Notable `RelayWindow`：平静OnUseから4秒、指定Qの本体ダメージ+v%。`AS(m,tr,v)` は新規Notable `AllyShield`：その記憶の指定イベントで自分と10m以内の味方旅人に各自の最大HPのv%の障壁、4秒。いずれも詳細は機構表を正とする。

|入口テンプレート|e1 / e2 / e3 / e4 / e5 / e6（6個すべて独立した星）|取得時に効く根拠|
|---|---|---|
|A(m)|D(m,1) / B(m,2) / D(m,1) / B(m,2) / D(m,1) / B(m,2)|X/S/E/C/Nの本体ダメージと既存幹2の仕掛け。入口への接続には幹2取得を必須にする|
|U(T)|B(T,2) / H(T,1) / B(T,2) / H(T,1) / B(T,2) / H(T,1)|既存幹2の平静OnUse Shieldと、平静本人の再使用。平静にDやOnHitを割り当てない|
|M(F)|H(F,0.5) / H(F,0.5) / H(F,0.5) / H(F,0.5) / H(F,0.5) / H(F,0.5)|変光星のタイマー本人への常時補正。使用・回避イベントを起こさない新しいHの経路|

全Bは加算してから乗算し、小数を保持する。記憶・橋・外縁のどこでも、B(m,*)の購入には対象記憶の幹2取得を要求する。同一効果への複数の新規Gは後述の同一チャンネル合成で量へ加算する。追加Gの値は既存の値を置き換える意味ではない。BにはReload、上限を増やせない回数、固定ダメージ以外の列挙Argを含めない。効果ごとの上限は後述。無意味なChanceやExtraTargetsは本設計では使わない。

新規メモリ星団のIDは `yubar.mem.<slug>.c1`〜`c4`。各行から `.e1`〜`.e6`、`.n1`、`.n2`、`.x` の**9星**を生成する。選択肢 `.x.a/.x.b` は効果識別子であり、追加の星ではない。fanは入口2本×3星、ringは6入口の半輪、chainは6入口の直列。いずれもn1/n2を経てxへ接続する。中心2星を通らず選択肢のParamだけに到達できない。別の枝から来ても幹2の効果所有条件を満たす。
