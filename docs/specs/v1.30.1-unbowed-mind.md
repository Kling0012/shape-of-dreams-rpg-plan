# 不撓の心（v1.30.1）

2026-10-03の利用者指定：「スタンだけに限定して、アンストッパブルをシールドと同じ秒数付与」。先のスロウ対応案や単純な障壁量増加案は採用しない。

- 敵由来のスタンで発動。最大HP×効果値%の障壁とアンストッパブルを各4秒、8秒に1回。
- 値4〜8、通常合計上限12は据え置き。Armor / Feet の抽選、保留していた一般固有品16個とセット1組を有効化。既存Power ID84を維持。
- スロウ、ノックバック、自己・味方・不明の発生源、すでに妨害無効中の付与は対象外。これらは再使用待ちを消費しない。
- EntityStatus.AddBasicEffect をHarmonyで観測。Prefixで妨害無効を確認し、Postfixで有効になったStunEffectを受け取る。StatusEffect.info.casterとvictimの敵対関係を確認してホストだけが適用する。
- 本体Actor.CreateBasicEffectでSe_GenericEffectContainer + UnstoppableEffectを4秒生成。障壁とは別の本体タイマーで管理し、障壁の破壊ではアンストッパブルの持続時間を短縮しない。区画切替・ホスト解除時は自分の効果のみ破棄する。プールで別用途に再利用されたコンテナは壊さない。
- 本体EntityStatusの集計はUnstoppable中のスタン・スロウ等を抑制する。元の状態異常を一律に削除する独自処理は足さない。既に中断された攻撃や移動を巻き戻す効果ではない。
- 内容表との照合は全559行・24セットを対象にし、P37の除外を削除。全体は固有品1190（一般1046・セット品144）、セット48、連携付き357。

## 検証

発動条件・再使用境界を純C#の試験で確認。実際のHostAuthority.UnbowedMind.csをネイティブAPIのテストダブルと一緒にコンパイルして、ホスト限定・敵限定・同時付与・効果の分離・解除を検証する。本体DLLを参照したReleaseビルドでも接続を確認する。テストダブルはゲーム内の通信や演出を再現しないため、実機戦闘と協力通信は未検証。

全1,615件の試験に成功。本体参照のReleaseビルド成功（既存のUnity非推奨警告2件）。ゲームのModsフォルダには配置せず、配布用の一時フォルダにビルドした。
