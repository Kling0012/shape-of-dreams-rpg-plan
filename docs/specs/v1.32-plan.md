# v1.32 計画（2026-10-04）

v1.32 の内容：6部位セットの調整、低レアの装備を増やす、星図の効果の追加（獲得コイン・夢のダスト、遠征を通して成長する星、空殻のアイデンティティ記憶の改変）。

## 1. 6部位セット

v1.31.0 で48セットすべてを6部位にし、6点のセット効果を追加済み。v1.32 では BalanceSim で6点効果の強さを確かめ、突出・不足を調整する（数値の調整のみ）。

## 2. 低レアの装備を増やす

設計は [v1.32-low-rarity-volume.md](v1.32-low-rarity-volume.md)。段階は次のとおり。

- 2a（v1.32.0）：家系（Family）と色づけの抽選、既存360の土台の家系タグ、新しい土台240（各枠60→100）。無垢の土台は今と同じ乱数列で同じ結果になる回帰試験を最初に書く。
- 2b（v1.32.1）：銘品360（アンコモン・レア・エピック）と組30、図鑑の分類。
- 2c（v1.32.2）：家系・組の称号と、組の完成の星XP。
- 保存形式は上げない（銘品は任意キー `named`）。ID は追加のみ。
- 新しい土台のアイコン240枚は、画像の作り方を決めてから入れる（決まるまでは土台の家系の紋章で区別し、絵のない土台は出さない）。

## 3. 星図の効果の追加

基本ゲームの仕組みとの相性を先に調べる（[v1.32-research.md](v1.32-research.md)）。そのうえで次を設計し、`tools/star-manifest/` のデータとして全旅人の星図に組み込む。

- **獲得コインを増やす星**・**夢のダストを増やす星**：外縁の星団に置く。協力プレイではホストが各旅人の分だけ増やす。能力値だけの星は全体の2割以内という方針を守るため、単純な%だけでなく、条件（撃破・確保・潜行の深さなど）と組み合わせた星にする。
- **遠征を通してスタックで永久成長する星**（空殻とタンク役の旅人）：遠征中の行動（被弾・ブロック・撃破など、旅人の役割に合うもの）でスタックが溜まり、その遠征の間は失われずに能力が伸びる。上限を設け、夢の圧とのつり合いを BalanceSim で確かめる。
- **空殻のアイデンティティ記憶の改変**：今は「次の基本攻撃を強化」で、成長型の精髄「神聖の信仰」と相性が悪い。アイデンティティの発動を、成長型の精髄が伸びる行動につなげる改変（2択の星・刻印）を用意する。

## 4. 進め方

- エンジン（抽選・保存・仕組み）は Sonnet、データ入力（土台・銘品・星）は GLM の検証つき方式で、並列に進める。
- 星図のポイント上限は500のまま。新しい星は既存のIDを変えずに追加する。
- 公開前に Core の試験・ビルド・実機の目視確認を行う。
