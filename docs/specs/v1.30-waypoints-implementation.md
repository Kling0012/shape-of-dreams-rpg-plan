# v1.30 道標の実装記録 / Waypoint implementation

道標は確保地点で選ぶ、次の1ゾーンだけの決まりです。契約とは独立して3枚を提示し、1枚を選ぶか、何も選ばずに進めます。選択は確保地点を離れるまで保留し、確保でも潜行でも同じように有効になります。次の確保地点に着いた時点で失効し、遠征の終了時にも消えます。

A waypoint is a rule for the next zone only. Each secure point offers three distinct cards independently of pacts. Selecting none is valid. The choice takes effect when securing or delving finishes, expires on reaching the next secure point, and is cleared when the run ends.

## 保存と権限

`Waypoints.cs` はゲーム本体に依存しないデータと計算を持ちます。`Waypoints.Totals` は読み取り専用の定義を再利用し、ホストが回復・障壁・記憶・召喚・夢の圧・悪夢化へ適用します。`Rules` は撃破報酬、確保地点、選択、有効化、失効を扱います。敵の遺物だけを変更し、買い物、出来事、遺失物の回収、依頼報酬、既存の所持品には適用しません。

`RunState` は有効な道標、保留中の選択、3枚の候補、世代、部屋ごとの受取済み記録、枠の巡回位置、宝庫の預かり品を持ちます。コピーとプロフィール保存の両方で保持します。古い保存に新しい項目がない場合は「道標なし」、深さ0になります。プロフィールのリセットは不要です。

候補は既存の遠征用乱数の状態から重複なしで選び、一度の到着で一度だけ生成します。協力時の候補と決定はホストが所有し、各参加者の個別戦利品の乱数とは分けて同期します。個別に確保するタイミングによって共有の道標を変えることはありません。

## 確認した経路と判断

- `Loot.RollKill`、`Loot.RollRelic`、`Content.MaxEnhanceFor`、`Content.SalvageShards`：`src/SodRpg.Core/Game/Loot.cs` と `Content.cs` の既存実装で確認。遺物の再抽選では、その枠の固有品・特性・固有効果の規則を保ちます。
- `Rules.BeginRun`、`ReachSecurePoint`、`Secure`、`Delve`、`OnKill`、`EndRun`：`src/SodRpg.Core/Game/Rules.cs` で既存の契約と確保の境界を確認。道標は契約の解除とは独立して次の到着で失効します。
- `ZoneManager.currentRoomIndex`：`.ref/dump/ZoneManager.txt` のプロパティを確認。部屋の上限は突破数の通知順に左右されず、同じ部屋への再訪でも復活しません。Core単体の呼び出しは突破数を代用できます。
- 回復・障壁・記憶・召喚・敵補正に使う本体APIは、ホスト側の実装記録に確認箇所をまとめています。CoreへUnity参照は追加していません。
- 実体のエリートを複製する案は採用せず、既存の悪夢化選択を使う「悪夢狩り」にしました。敵の生成数や本体の進行を変えず、狙う敵と報酬が変わります。
- 部屋あたりの上限は生成した報酬に対して適用します。かばんが満杯で処理された遺物も1つに数えます。紫の蜃気楼では、その満杯処理による欠片も発生しません。
- 宝庫の経験は即時に獲得します。ボス判定は元の敵種別を使い、悪夢化で戦利品の等級が上がっても預かり品は解放しません。未回収の宝庫は次のゾーンと遠征終了で失います。預かる遺物は256個までで、それを超える分は通常の分解価値の欠片として預かります。
- 複製した遺物は同じ内容でも個体IDを別にします。星への供物と目覚めの巡礼は夢の深さの倍率を最後に一度だけ掛けます。覚醒先が装着されていないときの喪失はカードで明記しています。
- 最初から強化された遺物にも既存の強化の節目を適用します。素朴な鍛冶場の強化+4には、通常の強化+3で得る特性1行も含まれます。
- 回避とUltimateのクールダウン、属性スタックの消費、アイデンティティの発動規則は変更しません。新たな発動間隔は追加していません。

自動検証は候補の再現性、未選択、選択の失敗時に変更しないこと、有効期間、全24枚の効果、部屋再訪、保存とコピー、素材変換、宝庫の精算、夢の深さとの丸めを対象にしています。実機での協力プレイと表示の確認は未実施です。
