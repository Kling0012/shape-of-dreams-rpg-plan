# 敵の見た目の差し替え（PR #25 の作り直し）計画

PR #25（v1.28 ごろの開発ブランチ上の draft）を、最新の main（v2.7.1）の上で作り直す。範囲は **10体の自作モデルで、本体の敵の見た目を差し替えるだけ**（新しい行動を持つ敵は作らない）。

## 方針

- 見た目の差し替えは、協力プレイの全員が同じモデル一式を持っているときだけ有効にする。1人でも合わなければ、全員の見た目を元に戻す（ゲーム自体は止めない）。AI・当たり判定・報酬は変えない。
- 設定は初期値オフ。オフなら独自の通信もしない。
- **SHA-256 による照合は使わない。** モデル一式の一致は、マニフェストの `contentVersion`（制作ツールが作り直すたびに更新）、各バンドルのファイルの大きさ、ゲームの版と Unity の版、ビルド対象で判定する。
- アセットバンドルは、この PC の Unity 6000.0.77f1（ゲームと同じ版）でバッチモードで作る。
- 見た目・アニメーション・協力プレイでの一致の確認は、実際に遊ぶときに行う（それまでは「未確認」と明記する）。

## 作業

1. 本体側：PR #25 の読み込み処理と全員一致の同期（Core の Mob*、Mod の MobModel*、設定、試験）を main へ移し、SHA-256 を外す。
2. 素材と制作ツール：10体の素材（assets/dreamborne）、展開・検査・梱包ツール、Unity 用の制作スクリプトを移し、SHA-256 を外す。
3. この PC の Unity で10体分のアセットバンドルを作り、MOD の配布物に入れる。ゲーム側の型や URP の版で合わない点があれば、推測で埋めずに一覧にする。
