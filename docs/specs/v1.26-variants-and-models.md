# v1.26「夢の変種を増やす・新しいモデルの試験」

利用者の助言（2026-10-02）：アイテム数はできるだけ増やす。新しいモンスターを作れたら一番すごい（Blender・BlenderMCP、Lab の3D生成の利用可）。

1. **夢の変種を 13→25 種**：まだ変種のない本体の敵（森の蜘蛛2種、闇の洞窟の精と洞主、絶望の地の位相のずれと羽虫、墨の剣霊と大虎、溶岩の巨獣と狼、空の星核、雪山の首長）に1種ずつ。既存の性質（結界・棘皮・飢渇・破甲・一撃の上限・死に際の爆発）の組み合わせで、それぞれ違う戦い方を求める。
2. **新しいモデルの技術検証**（層C の第一歩）：本体の敵1体の見た目を、別のモデルに差し替える試し。
   - Unity の版を調べ、同じ版で AssetBundle を作れるか確かめる。
   - Blender（BlenderMCP）で簡単な静的モデルを作り、`EntityVisual.LoadModelLocal` で差し替えられるかを実機で確かめる。
   - Lab（RTX 3090）に 3D 生成（Hunyuan3D など）を入れて、下書きのモデルを作れるか試す。
   - 結果（できた・できない・理由）を記録し、本格的な新モデルに進むかを決める。
