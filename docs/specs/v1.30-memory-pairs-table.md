# v1.30 記憶どうしの合わせ技 設計表（橋 62か所）

設計の元は [v1.30-horizontal-ideas.md](v1.30-horizontal-ideas.md) の A1。仕掛けの枠組みは [v1.28-memory-gimmicks.md](v1.28-memory-gimmicks.md)、各ルートの既存の仕掛けは [v1.28-memory-gimmicks-table.md](v1.28-memory-gimmicks-table.md)、記憶の動きと「遠征の前に選べる装備」は [v1.27-traveler-kits.md](v1.27-traveler-kits.md) を正とする。この表は設計のみで、コードは含まない。既存の仕掛けと同じ効果は作らず、「2つの記憶がそろったときだけ起きる2段の動き」に絞った。

## 1. 星図の枝の新しい並び（決定済み）

同じ枠の候補どうしが隣り合うと同時に装備できない問題は、例外の仕組みではなく、**枝の並びを変えて**解決する。放射状にこの順で隣り合い、最後は最初につながる。「A」「B」は travelers.json の loadout の並び順（v1.27 キット一覧の末尾の表の順）。

- 7ルートの8人：**アイデンティティA → Q-A → R-A → 移動 → アイデンティティB → Q-B → R-B（→ アイデンティティA）**
- Bismuth（6ルート）：**プリズムの視界 → 無垢な魂 → 歪な疾走 → 業火物語 → 勇敢なる心 → 歪な精神（→ プリズムの視界）**

橋（夢の輪）は、隣り合う2本の枝の**4番目の星**（`RouteOrder = 4`、3段の星）の間にある。この並びなら、橋の両側は必ず違う枠どうしなので、両方を同時に装備できる。

| 橋 | 7ルートの旅人 | 枠の組み |
|---|---|---|
| ① | アイデンティティA × Q-A | ID×Q |
| ② | Q-A × R-A | Q×R |
| ③ | R-A × 移動 | R×移動 |
| ④ | 移動 × アイデンティティB | 移動×ID |
| ⑤ | アイデンティティB × Q-B | ID×Q |
| ⑥ | Q-B × R-B | Q×R |
| ⑦ | R-B × アイデンティティA | R×ID（最後から最初へ戻る橋） |

Bismuth の橋：①視界×無垢な魂、②無垢な魂×歪な疾走、③歪な疾走×業火物語、④業火物語×勇敢なる心（QR×QR）、⑤勇敢なる心×歪な精神（QR×QR）、⑥歪な精神×視界。QR×QR の橋（④⑤）は、**その2つを両方装備したときだけ**働く（Bismuth は4つの QR から2つを選ぶので、起きるのは6通りのうち1通り）。無垢な魂が関わる①②は、無垢な魂が Q 枠・R 枠のどちらにあっても成り立つ。

残りの夢の輪（7ルートの旅人は8個目、Bismuth は7・8個目）は6番目の星の間にある外側の橋で、この表の対象外。今のまま夢の輪の能力値として残す（要確認：外側の橋にも合わせ技を置くかは別の判断）。

### 有効条件

1. 橋の星に1段以上。
2. 橋の隣の2つのルート（4番目の星）に、どちらも1段以上。
3. その2つの記憶を**両方とも装備**している。

## 2. 合わせ技の共通の仕組み

2つの記憶が「A の動き → B の動き」の順に働く（表の「ルートA」「ルートB」は橋の隣り合う順で、引き金になる方は各行に書いた）。つなぎには既存の Expose の窓（4秒、重ならず延長）を使う。

- **印**：片方の記憶が敵に当たったとき、その敵に「このペア専用の印」（Expose の一種、4秒）を付ける。段が上がると印の脆さが 2/3/4% になる。ほかの仕掛けの Expose とは**別のID**で持ち、ほかの Expose の星で偶然反応しないようにする。
- **窓**：当たりが出ない記憶（使用だけで効く）のときは、使った瞬間に自分へ4秒の「窓」を開く（Quicken・Empower と同じ4秒の窓だが、能力値は上げない）。
- **段2**：もう片方の命中・会心・撃破が「印のある敵」（または窓の間）に当たったときだけ効果が出る。
- 表の「効果の指定」の書き方：`① 起点: トリガー → 印/窓 ／ ② 受け手: トリガー[条件] → 効果 値(1/2/3段) Arg CD`。値は橋の星の1・2・3段目の値。
- 目安は v1.28 に合わせた。Burst 30〜100、Echo 15〜40、Shield・Heal 1〜8、Recharge 10〜30、RechargeOther 10〜15。
- 追加のダメージ（Burst・Echo）は属性なし・連鎖なし（v1.28 の決まり）。回復・障壁は `serverActor` 経由で、Nachia の団結を自動で付けない。属性の付与は既存の `Actor.ApplyElemental` 経由で、スタックを消費しない。
- 間隔（CD）は、命中が連続する記憶の段2にだけ置き、理由を書いた。印や窓を付ける側は延長されるだけなので間隔は要らない。
- **回避（移動の枠）を引き金にする効果は置かない。** ダメージのない移動の記憶は**受け手だけ**：相手の動きで移動の再使用が近づく（Recharge、相手指定）。ダメージのある重装タックル（Vesper）とフロストチャージ（Cetus）だけは、引き金にもなる。
- 「アイデンティティ」は遠征の前に選べる2つだけを考える（共通のアイデンティティは考えない）。ペアに入っていないほうのアイデンティティを装備していても、Q・R・移動のペアは成り立つ。

### 新しい仕組み（最小限）

| 記号 | 内容 |
|---|---|
| N0 | ペアの有効条件（上の3つ。v1.26 の連携の `Requires` を仕掛けにも付ける）と、**印・窓の照会**（印のある敵への命中・会心・撃破、印のある敵が倒れたとき、窓の間の命中）。Expose の4秒の台帳にペアIDを足す程度。 |
| N1 | Recharge の**対象を相手の記憶に指定**する。アイデンティティはクールダウンを持たないので、アイデンティティが引き金のときは相手の Q・R・移動を対象にする。移動の記憶へも使えるが、回避の発動を引き金にはしない。 |
| N3 | 基本攻撃を撃ったときの引き金（生命の循環のようにダメージのない基本攻撃用）。召喚獣がいるときだけ働く。Nachia の2組だけ。（旧版の N2「どちらかの装備」は、枝の並びを変えたので不要になり削除した。） |

- 間隔（CD）を置いたのは13組（残り49組は間隔なし）。理由は、連続して当たる記憶（洗礼の追加火炎、礼儀注入、電撃、跳ね返り、猟犬、基本攻撃、貫通3連、ゴールデンバーストの連打）の命中ごとに発動するのを防ぐため：Vesper ⑥⑦、Lacerta ⑤、Cetus ④⑤⑦、Yubar ⑤、Nachia ②⑤、Aurena ①②⑥、Bismuth ⑤。

### 新しい仕組みが要る組

- **N0**（有効条件）：全62組が前提。そのうち印・窓の照会が要るのは54組（残り8組は「相手の動き → 移動の再使用」だけ）。
- **N1**（Recharge の対象を相手の記憶に指定）：18組。うち14組は移動の記憶が受け手（Lacerta ③④、Yubar ③④、Husk ③④、Mist ③④、Nachia ③④、Aurena ③④、Bismuth ②③）。残る4組は、アイデンティティが引き金で Q・移動を対象にするもの（Vesper ④、Lacerta ⑥、Yubar ⑦、Mist ⑤）。
- **N3**（基本攻撃の引き金）：2組（Nachia ④⑤）。
- N2（どちらかの装備）は、枝の並びを変えたので不要になり、削除した。新要素はどれも小さい：印・窓は既存の Expose／Empower の4秒の台帳にペアIDを足すだけ、N1 は既存の `ApplyCooldownReductionByRatio` の対象指定、N3 は既存の基本攻撃の通知。

### 同じ枠が隣り合う橋

新しい並びでは、62橋すべてが違う枠どうしで、同じ枠の隣り合いはない。QR×QR は Bismuth の④⑤だけで、両方装備が条件（6通りのうち1通りで起きる）。

### その他の注意

- ダメージのない移動の記憶（Lacerta、Yubar、Husk、Mist、Nachia、Aurena、Bismuth）は受け手だけ。回避の発動を引き金にしない決まりのため（14組）。回避後の短い窓を許すなら、移動の記憶が起点になる組を増やせる。判断は保留。
- 印の Expose は2〜4%だけで、ほかのルートの Expose（8〜15%）と別ID。2つが重なっても、脆さは最大値の1つだけ（v1.28 の決まり）。
- 外側の橋（8個目。Bismuth は7・8個目）は今のまま夢の輪。
- 並びの変更は `HeroTreeLayout` の枝の並べ方（`RouteId` の初出順）に依存するため、`HeroStarRoutes.cs` の登録順を、新しい並びに合わせて書き換える必要がある（この文書の範囲外）。
- 検証案（Core の試験）：①2つの記憶を両方装備していない組は起動しない、②橋・隣接星の段が足りないと起動しない、③Burst・Echo の追加ダメージからは印・窓が増えない、④すべての橋が違う枠の組であること、⑤ペアに入っていないほうのアイデンティティを装備しても Q・R・移動のペアが成り立つ。
