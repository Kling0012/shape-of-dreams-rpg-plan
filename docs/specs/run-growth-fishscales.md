# ヴェスパーの鍛錬の上限をなくす（#781）

魚の鱗で減った最大HPを取り戻す処理は `HostAuthority.RunGrowth.cs` の `RestoreFishScalesMaxHealth`（gh-auto で先に入った実装）。

- 2026-10-18（利用者決定）: 「傷を糧にする」の蓄積の上限はなくす（`growth/cap = 0`）。体で受けたダメージでしか溜まらない鍛錬で、魚の鱗の下では被弾のたびに急死の危険が増えるため、溜めた分が上限で止まらないようにする。
- 上限を増やすだけだった「積もる傷痕」（`vesper.run.m1`）と「耐え抜いた証」（`vesper.run.m2`）は、ケトゥスの2星と同じく1スタックの効果 +25% に変える。閾値11%HP・1スタックの効果量・選択肢は変えない。
