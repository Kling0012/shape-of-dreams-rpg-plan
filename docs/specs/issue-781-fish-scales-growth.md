# 魚の鱗と遠征の鍛錬の組み合わせの修正（Issue #781）

2026-10-18の報告「ヴェスパーの鍛錬の効果が、悪夢の『魚の鱗』と相性が悪すぎる」に対して決めた修正と理由。再現の記録は [tests/repro/issue781/README.md](../../tests/repro/issue781/README.md) を参照。

## 確かめたこと

本体の明晰夢 `LucidDream_FishScales` は全ヒーローに状態 `Se_FishScales` を付ける。この状態は、モンスターからの被ダメージ（失ったHP）に通常敵0.3・ボス0.4（近接旅人は×0.65）を掛けた値を累積し、`StatBonus.maxHealthFlat = -累積値` で最大HPを減らす。減少はゾーン移動とノックアウトで0に戻る（`Dew.Contents.dll` の逆コンパイルで確認）。

一方、MOD側の鍛錬の溜まり（`OnRunGrowthDamage`）は、失ったHPを「その瞬間の」最大HPへの%で数えていた。魚の鱗で最大HPが減ると分母が縮み、同じ傷がより大きな%として数え直される。方向は「溜まりすぎて強くなりすぎる」で、逆（溜まらず弱くなる）は起こらない。模型シミュレーションで、同じ傷を与えても魚の鱗ありでは毎ゾーン鍛錬が先行し、基礎最大HP2000では上限60への到達が1ゾーン早まることを確認した。

## 決めた修正

- 失ったHPと障壁の吸収を最大HPへの%へ換算するとき、魚の鱗で見かけ上減った分（`Se_FishScales.GetAmount()`）を分母へ足し、減らされる前の最大HPで数える。`RunGrowth.HealthPercent` に3引数のオーバーロードを加え、ホストは両方の契機（失ったHP・障壁の吸収）で使う。
- 魚の鱗を付けていないときの補正量は0で、それまでの計算と同じになる。クールダウン・閾値・上限・効果量は変えない。ケトゥスの鍛錬（障壁の吸収で溜まる）にも同じ補正が働くが、これも魚の鱗を付けているときだけの変化である。

## 確認と未確認

- 確認済み: 再現テスト（`Issue781FishScalesGrowthReproTests`。同じ傷で魚の鱗の有無による段数の差が許容内に収まること）が修正後に成功し、修正を一時的に戻すと失敗すること。鍛錬の数値と通常時（魚の鱗なし）の挙動を検査する既存テスト（`RunGrowthBalanceTests`・`BalanceSimV132StarsTests`・`StarAdditionsV132Tests` など）が成功すること。実際のゲームDLLに対するMODのReleaseビルド。
- 未確認: ゲームを起動しての確認（この環境では起動不可）。
