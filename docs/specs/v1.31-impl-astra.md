## Questions and stopped bindings

1. The C06 ordinary shield pool and C07 explicit Calm selection must be connected before enabling the C08 key or shield-bearing C05 registrations. The legacy aggregate `StillWater` value cannot identify that key. Its old reward must be removed through explicit migration without removing unrelated contributions. C08 requires a real pool dispatcher; C05 shield registrations currently reject.
2. Native Ultimate-lifetime bridge windows and phase-sensitive sources other than the verified Baptism explosion path remain stopped at host registration. No unclassified hit is treated as an initial explosion and no estimated lifetime replaces the native callback.
3. C05 currently binds immediate recharge and generated single-target damage. Area/DoT/other payoff families require declared payload data and verified handlers. Kill-triggered single-target damage rejects because its killed victim is not a surviving receiver; no target substitute is selected.
4. Authored registration, scoped modifier/keystone production and Build/transport integration remain with their assigned engines and the data registry. These changes do not register the 7,500 designed stars or invent a parallel serialized format.
5. Native code/IL inspection, installed-DLL metadata checks, Core tests and compilation do not constitute live combat verification. Live patch installation, native pooling/coroutine timing, cooldown processors/configurations and multiplayer behavior remain acceptance checks.

### Engine

`src/SodRpg.Core/Game/Mechanisms/MemoryActivationAttribution.cs` provides immutable activation and notification identities, explicit payload/generated-origin enums, exact native adapter registration, equipment epochs, pooled-instance bindings, packet notification deduplication and the four explicit quota forms. Serial allocation is monotonic and independent of wall-clock time. A native extra payload can retain its original activation serial while declaring its exact source; a fresh passive discharge can instead allocate a new serial. No source is inferred from an element, frame, nearest actor or class-name prefix.

`SetEquipment` preserves the epoch and consumed quotas for identical equipment retransmissions. Actual equipment changes, death/session/zone reset and pooled-object lifetime boundaries invalidate pending identities. Native equipment tracking also compares the actual equipped trigger instances and observes server equip/unequip mutations immediately, including removal and re-equipping of the same object between events. Core keeps no Unity references and remains C# 9 / netstandard2.0.

Consumers call `TryAdmitNotification` to deduplicate the same packet propagated through different ancestors. Hit and CriticalHit remain distinct notifications of the same packet. `TrySpend` commits PerActivation, PerActivationVictim, PerKill or PerOwnedBasicAttack quota only after the effect condition succeeds. Channel identity preserves independent effect budgets. PerKill uses the victim's native lifetime identity. An owned primary hit and its native additional packet share the real attack serial where the adapter declares that relationship; the additional packet cannot spend an owned-primary quota.

### Native host binding

`HostAuthority.MemoryActivationAttribution.cs` publishes confirmed use, native hit/critical/kill, completed owned fired attack and successful owned primary-hit events with their final damage amount. It binds cast roots before native preparation can deal damage, then propagates the captured identity to descendants. Exact native child types require their specific adapter at creation and lookup, so a rejected child cannot acquire the long-lived parent's activation through ordinary ancestry traversal. Known direct scopes are authoritative: a mismatching or already-consumed direct packet stays rejected.

The precise `Actor.DoBasicAttackHit` call to `Actor.DealDamage` is wrapped using a checked transpiler. Exactly one matching call is required; a changed native method fails explicitly. This marker identifies the actual main packet even when native attack-effect strength is zero, while nested/native added packets cannot claim it. The main packet's actual attacker must match the captured owner. Final admission occurs after positive final native damage, not at the earlier hit callback. Misses therefore publish a completed fired notification without consuming C09 preparations.

Circle of Life uses one canonical fired notification while its actual identity is equipped and a live own summon exists. The event retains the fired instance's attack serial and declares the equipped source. It is neither an invented SkillUse nor a repeat of the native heal/lifetime handler. Generic ordinary basic attacks retain an empty memory source. Memory-specific overrides additionally publish memory Hit/CriticalHit notifications using the same packet and attack serial.

Each native summon attack receives a fresh attack serial at its actual before-prepare callback. The adapter requires the real summon caster, the summon's captured hero caster, and the same actual equipped SkillTrigger ancestor; Movement, Gem and elemental ancestry cannot enter this path. Summon descendants keep that attack serial and cannot publish or spend an owned-primary notification. Killing Flow projects only the verified primary damage packet while its actual Identity is equipped; it does not relabel the fired instance or its other packets, and an existing authoritative native memory source keeps precedence.

### C02 native delayed/ending payload adapters

### C04 DirectedRecharge

Implemented in `src/SodRpg.Core/Game/Mechanisms/DirectedRecharge.cs`:

- Immutable real-equipment snapshots contain owner, epoch, exact memory name, native instance identity, slot, and actual Normal/Ultimate type. Negative nonzero Unity instance IDs are valid. Duplicate memory names, slots or instances reject the complete snapshot.

- Each named channel sums its equivalent value contributions in hundredths of a percent, applies one explicitly scoped modifier, then its declared cap. Independent channels stay independent.
