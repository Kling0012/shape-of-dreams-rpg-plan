# v1.27「プロフィールのリセット」

利用者の指示（2026-10-03）：次は大規模変更なので、プレイヤーのデータや所持品を一度リセットする。

## リセット
- 保存の版（`Profile.CurrentVersion`）を 1 → 2 に上げる。
- 版1の保存を読んだときは、プロフィールを**新しく始める**（夢のレベル・所持品・素材・星図・図鑑・実績・統計をすべて初期状態に）。
- 前のデータは消さない：`profile.json` を `profile.v1-archive-<日時>.json` として同じフォルダに写してから始める（`.bak` も同様に写す）。
- 起動時の知らせ：「大きな更新のため、プロフィールを新しく始めました。前のデータは profile.v1-archive-… に残しています。」
- 版2の保存は今までどおり読む。版2より新しい保存は今までどおり読まない。
- 協力プレイ：各自のプロフィールは各自の PC にあるので、全員が v1.27 を入れた時点でそれぞれリセットされる。

## 試験
- 版1の保存を読むと新しいプロフィールになり、写しが残り、知らせが出る。版2はそのまま読める。
