# v1.14 仕様：見た目（遺物のアイコンと画面のデザイン）

担当：絵の指示・画面のデザインと実装は Claude（フロントエンド）、アイコンの画像は Codex の画像生成。
利用者の希望（2026-10-02）：UIのデザインにこだわる。視覚的なところは大事。アイテムの図など必要な画像は Codex などで生成してよい。

## 1. 遺物のアイコン（装備の土台 45 種に 1 枚ずつ）

- 固有品・セット品は土台のアイコンを使い、レア度の色の枠で見分ける（伝説は金、セットは橙）。
- 生成：Codex の画像生成で 1024×1024・透明背景の PNG を作り、128×128 に縮めて MOD に同梱する（`icons/<土台id>.png`、1枚 約8KB、合計 約400KB）。
- 生成した画像はこのMODのために新しく作った物で、本体や他作品の素材は使わない（Workshop の規約）。

### 共通の絵柄（全アイコンに同じ指示を付ける）

> ダークファンタジーの「夢の世界」のアイテムアイコン。手描き風のペイント調で、輪郭がはっきりしていて、64px に縮めても形が分かる。アイテム1つだけを、画面の中央に斜め45度で大きく描く。背景は透明。文字・ロゴ・枠・影の地面は入れない。系統ごとの差し色：破壊＝赤〜橙の残り火、生命＝緑〜青緑の淡い光、想像＝青〜紫の星屑。

## 2. 画面での使い方（Claude が実装）

- アイコンは必要になったときに一度だけ読み込んでキャッシュする（`Texture2D.LoadImage`、`ImageConversionModule`）。毎フレーム読み込まない。
- 遺物の一覧の各行：左に 24px のアイコン＋レア度の色の細い枠。
- 遺物の詳細：上に 64px のアイコン、レア度の色の枠。
- 装着中の3枠：名前の左に 24px のアイコン。
- アイコンが見つからないときは、今まで通り文字だけで表示する（落ちない）。

## 3. 画面のデザイン（Claude が実装）

- レア度の色をそろえる（コモン灰・アンコモン緑・レア青・エピック紫・伝説金・セット橙）。
- 見出し・区切り線・パネルの余白を整え、情報のまとまりを見やすくする。
