## 見つかった問題

1. **ダメージを出す固有効果は、すべて攻撃力だけで計算している**（`HostAuthority` で `hero.Status.attackDamage`）。
   - 対象：烈火（通常攻撃4回ごとの「魔法ダメージ」）、雷鎖（魔法ダメージ）、爆砕、旋風、四元、処刑、先制。
   - 本体の旅人は9人中7人が魔力中心なので、多くの旅人で効果が弱い。特に「魔法ダメージ」なのに攻撃力で伸びるのは不自然。
2. **能力を上げる固有効果のうち、逆襲（被弾後）と万全（HP80%以上）は攻撃力だけを上げる。** 魔力の旅人には効かない。
3. **刻印（星図）と旅人の食い違い：**

| --- | --- | --- |

## 直し方

### A. 固有効果の計算を、旅人の伸び方に合わせる（全員に効く）

- 「魔法ダメージ」と属性のダメージ（烈火・雷鎖・四元）は、**攻撃力と魔力の高い方**で計算する。
- 爆砕・旋風（周囲へのダメージ）も**高い方**で計算する。
- 処刑・先制は「通常攻撃への上乗せ」なので**攻撃力のまま**にする。
- 逆襲・万全は**攻撃力・魔力の両方**を上げる。
- 説明文も「攻撃力か魔力の高い方の X%」「攻撃力・魔力が X% 上がる」に直す。

### B. 刻印（星図）を旅人ごとに直す

| 旅人 | 変更 |
| --- | --- |
| Vesper | 「炎の誓い」を「聖なる力」（魔力 +4%）に。奥の星「審問官の呼吸」を「審問の光」（魔力 +3%）に。到達刻印「審問の構え」は A の変更で攻撃力・魔力の両方が上がる |
| Lacerta | 奥の星「徹甲弾」（攻撃力）を「火薬の調合」（魔力 +4%）に。通常攻撃の星は残す（基本攻撃が主体のため） |
| Cetus | 奥の星「深海の重み」（行動妨害耐性）を「深海の器」（最大HP +4%）に。「氷の殻」を 4→5% に |
| Yubar | 「星の導き」（会心率）を「星の魔力」（魔力 +3%）に。「遠い星」（射程）を「星の加速」と重ならない「重力の井戸」（スキル加速 +4）に。奥の星「超新星」（会心ダメージ）を「超新星」（魔力 +3%）に |
| Mist | 奥の星「鍛えた体」（最大HP）を「剣気」（魔力 +3%）に |
| Aurena | 到達刻印「血の献身」を過負荷（技を使った後の魔力 +20%）に。「満ちた聖杯」は A の変更で攻撃力・魔力の両方。奥の星「聖杯の閃き」（会心率）を「聖杯の叡智」（魔力 +3%）に、「捧げる狂気」（血の渇き）を「捧げる祈り」（過負荷 +4）に |
| Bismuth | A の変更で、四元・雷鎖が魔力でも伸びるようになる。刻印はそのまま |
| Husk・Nachia | 変更なし |

- 振り直しは無料なので、すでに振った星は、変わった星の段をそのまま引き継ぐ（同じ ID で中身だけ変える）。
- 試験：A の計算（攻撃力と魔力の高い方）、B の各旅人の星の能力値、旅人ごとに「本来伸ばすべき値」の星が1つ以上あること。

## 追記（2026-10-02）：属性付与を「確率」から「量」へ

利用者の指摘：Husk の「虚ろの刃」（通常攻撃で闇を付ける）は、これでは弱い。もっと多くスタックしやすくしないと。

いまの仕組みでは、影・火種・霜・輝きは「通常攻撃が当たると X% の確率で、属性を1つ付ける」。Husk の到達刻印でも 35% で1つしか付かず、闇を重ねて闇ダメージの技で叩く流れになるまでに時間がかかりすぎる。

**変更**
- 値 X を「100 ごとに確実に1つ、端数はその確率でもう1つ」とする。例：100 は毎回1つ、150 は毎回1つと 50% でもう1つ、200 は毎回2つ。
- 上限 80 → 250。
- 説明文を「通常攻撃が当たるたびに、敵に闇を X/100 スタック重ねる（端数は確率）。闇ダメージの技がよく効くようになる」に。

**Husk**
- 到達刻印「虚ろの刃」（影）：35 → 100。
- 奥の星「闇を纏う」（影）：1段 +8 → +20。
- 会心で当たったときは、さらに1つ多く重ねる（影を持つときだけ。会心の星・Ultimate と噛み合う）。

**ほかの旅人・装備**
- Lacerta「サラマンダーの火種」（火種）：30 → 90。Cetus「凍てつく潮」（霜）：35 → 100。Bismuth の頁（火種・霜・影）：1段 +6 → +15。Vesper・Yubar の輝きの星：1段 +6/+8 → +15/+20。
- 装備：エピックの候補の範囲 20〜35 → 40〜80。固有品の値は 2.5倍（上限 250）。
- 試験：100・150・250 で、重なる数の平均が 1・1.5・2.5 になること。会心で1つ多く重なること。
