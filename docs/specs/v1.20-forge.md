# v1.20「鍛冶を数値だけにしない」

利用者の助言（2026-10-02）：鍛冶や強化が、ただステータスを高くするだけになっていないか。

## 点検の結果

- 強化：+1ごとに能力値が6%（固有効果は5%）増えるだけ。+5まで同じ手触り。
- 再調律：特性1つを運任せで引き直す。結果を選べない。
- 合成：同じレア度3つ → 1つ上のレア度。何が出るかは完全に運。
- 製作：枠とレア度の下限を選べるが、それ以外は運。

## 方針

新しい仕組みは足さず、鍛冶のそれぞれの操作に**節目と選択**を入れる。

### 1. 強化の節目

- **+3**：特性が1行増える（その枠の候補から、まだ持っていない能力値）。
- **+5**：固有効果を持たない遺物（コモン〜レア）は、その枠の固有効果を1つ得る（エピックの候補の下限値）。すでに固有効果を持つ遺物（エピック・固有品）は、特性がもう1行増える。
- 節目は強化した瞬間に1回だけ起きる（遺物に「済み」の印を残す）。すでに+3・+5の遺物には、次に起動したときに一度だけ付ける。
- 鍛冶の画面に「次の節目：+3で特性が1行増えます」と出し、強化の知らせにも節目の内容を書く。
- 強化しても数値が少し増えるだけ、ではなく「+3と+5を目指す」目標になる。コモンでも+5まで育てれば固有効果を持つので、気に入った見た目や土台を使い続けられる。

### 2. 再調律は3つから選ぶ

- 調律石を払うと、その特性の**候補が3つ**出る（できるだけ別の能力値）。3つから1つを選ぶか、「元のままにする」を選ぶ。
- 払った調律石と回数（3回まで）は、選ばなくても戻らない。
- 候補は保存する（読み直しで引き直せないように）。候補が出ている間は、その遺物の他の操作（強化・分解・合成）はできない。

### 3. 合成の結果の枠を選ぶ

- 鍛冶の絞り込みで枠を選んでいるときは、合成の結果をその枠にできる（欠片が1.5倍）。「すべて」のときは、これまでどおり枠は運で、費用も同じ。

## ルール側（GPT）

- `Relic`：節目の印（`EnhanceMilestones`：0〜2）。保存と読み込み。
- `Rules.Enhance`：+3・+5の節目。`Rules.ApplyEnhanceMilestones(Profile)`（既存の+3・+5に一度だけ）。
- `Rules.Retune` → 候補を作って `Profile.RetuneOffer`（遺物・特性の位置・候補3つ）に保存。`Rules.ChooseRetune(p, index)`（-1で元のまま）。候補がある遺物の他の操作を止める。
- `Rules.Transmute(p, rarity, trades, Slot? target)`：枠を選ぶと費用1.5倍。
- 試験と BalanceSim（強化の節目で強さがどれだけ増えるか）。

## 画面（Claude）

- 強化ボタンの下に「次の節目」。節目を越えたときの知らせ。
- 再調律：候補3つをボタンで並べ、いまの値と比べて ▲▼ を付ける。「元のままにする」。
- 合成：枠を選んでいるときは「→ 頭（欠片45）」のように結果の枠と費用を出す。
