# 遊び方を横に広げる案（2026-10-03）

利用者の指示：前述のこと（能力値を伸ばすより遊び方を横に広げる、今の戦い方の邪魔をしない、旅人をよく調べる、間隔は最小限、敵側のつり合い、アイテムの数）を含めて、新しく遊び方を広げるためにできそうなことを考える。

「横に広げる」の判定：**選ぶものが増える／選び方で遠征の進め方や戦い方が変わる／組み合わせで新しい型が成立する**こと。数字が大きくなるだけのものは入れない。
下の各案には、何が広がるか・邪魔にならないか・本体のどの仕組みで作れるか（確かめた経路があるもの）・規模を書いた。

## A. 戦い方の「型」を増やす（装備・星図）

### A1. 記憶どうしの合わせ技（ルート間の橋）
- いま：星図の枝と枝の間の「橋」は夢の輪（汎用の能力値）。
- 案：橋の星を「2つの記憶の合わせ技」にする。両側のルートに振っていて、両方の記憶を装着しているときだけ効く。例：ハンドキャノンの命中で「印」を付け、精密射撃がその敵に当たると追加の爆発。森の呼応の猟犬が噛んだ敵は、月光の誓約のフェンリルの跳躍で回復量が増える。
- 広がるもの：Q×R、Q×移動、R×アイデンティティの組み合わせごとに「型」ができる。同じ枠の候補どうしは同時に持てないので、組み合わせは**違う枠どうし**だけ（travelers.json の loadout）。
- 邪魔にならないか：両方を着けているときだけ効くので、片方しか使わない人には何も起きない。
- 作り方：v1.28 の仕掛け（記憶の判定・OnHit/OnKill）と v1.26 の連携（条件に記憶2つ）をつなぐ。「印」は Expose の仕組みを使う。新しい本体の仕組みは要らない。
- 規模：9人 × 枝の間 7か所 ＝ 63個。設計は旅人のキットの照合が要る（Sonnet 設計 → レビュー）。

### A2. 属性の反応（2つの属性がそろった敵に起きること）
- いま：四元の共鳴（4属性すべて）だけ。
- 案：2属性の反応を固有効果にする。火＋冷気＝蒸気（周囲に鈍足と小さな爆発）、光＋闇＝蝕（その敵への与ダメージ増加・Expose）、火＋闇＝燃え殻（倒すと火を周りへ）、光＋冷気＝氷晶（シールド）。**スタックは消費しない**（氷の血脈・アンギリアンのスタックを壊さない）。
- 広がるもの：属性を混ぜる理由ができる。1人で2属性を持つ型、協力で属性を分担する型。
- 邪魔にならないか：反応は追加で起きるだけ。属性の上限（闇・光5、冷気1、火なし）に触れない。反応で出るダメージは属性なし・連鎖なし（v1.28 の決まり）。
- 作り方：`OnApplyElemental`（四元の共鳴と同じ経路）で、対象の `fireStack / hasCold / lightStack / darkStack` を見る。確かめ済みの経路。
- 規模：固有効果4〜6個。固有品とセットで使える。

### A3. 「変換」の刻印・固有品（資源の意味を変える）
- 案：ある値をほかの働きに変える、型を定義する固有効果。例：
  - 障壁が切れる・割れるとき、残量の X% を周りへダメージ（盾役の攻撃手段）。
  - 最大HPを超えた回復の X% を召喚獣の力に（回復役＋召喚の型。溢れる命の仲間）。
  - 記憶を使うたび、通常攻撃の次の1発に魔力の X% を乗せる（魔力で殴る型）。
  - 敵を倒すたび、いちばん近い味方の記憶のクールダウンを縮める（支援の型。回避・Ultimate は除く）。
- 広がるもの：「この旅人はこう戦う」の幅が、装備1つで変わる。
- 邪魔にならないか：変換は「追加」であって、元の働きを奪わない（攻撃速度を攻撃力にする Husk の一歩一殺と同じ形は避け、本体の変換と二重にならないものだけ）。
- 作り方：障壁の終了は本体の `Se_GenericShield_OneShot` の破棄を監視（要確認）、ほかは既存の処理。
- 規模：固有効果8〜12個（v1.29 の新しい固有効果44の中で優先）。

### A4. 装備の「継承」（固有品の効果を別の装備へ移す）
- 案：鍛冶で、固有品を素材にして、同じ枠のエピックにその固有効果1つを刻む（1つの装備に1回だけ）。元の固有品は消える。
- 広がるもの：効果の組み合わせをプレイヤーが作れる。「この2つを同じ枠で」ができる。再調律・限界突破と並ぶ鍛冶の選択肢。
- 邪魔にならないか：固有効果の合計の上限（PowerCap）はそのまま。連携は移せない（固有品の個性を残す）。
- 作り方：Core だけ（Relic に `Inherited` 1枠、Rules に `Inherit`）。費用は調律石と欠片。
- 規模：中。試験は Core で全部書ける。

## B. 遠征の進め方を増やす（ラン構造）

### B1. 確保地点の「道標」（次のゾーンの決まりを選ぶ）
- いま：確保地点では「確保／深く潜る」と契約だけ。
- 案：確保地点で、次のゾーンの**決まり**を2〜3枚から1枚選ぶ。例：「このゾーンの遺物はすべて武器」「エリートが2倍、報酬も2倍」「回復は半分、障壁は2倍」「属性の反応が2倍」「悪夢化が全部、覚醒の力3倍」。ゾーンが終わると消える。
- 広がるもの：遠征ごとに進め方が変わる。自分の型に合う決まりを選ぶ判断。
- 邪魔にならないか：本体の仕組みはいじらず、MOD の値（ドロップの枠・報酬倍率・敵の強さ倍率）だけを変える。協力ではホストが選び、全員に同じ決まり。
- 作り方：RunState に「今のゾーンの道標」を持つ。既存の契約の仕組み（Pact の Totals）と同じ形で効果を合算。
- 規模：道標 20〜30種。契約・夢の出来事と役割がかぶらないよう、道標は「1ゾーン限りの決まり」に限定。

### B2. 「夢の深さ」を選ぶ（難易度の段を自分で選ぶ）
- いま：夢の圧は夢のレベルと星の数から自動。
- 案：遠征の開始時に「夢の深さ」0〜5 を選ぶ。段ごとに敵の強さ（夢の圧に掛ける）と報酬（レア度の幸運・覚醒の力・星の経験）が上がる。協力ではホストが選ぶ。
- 広がるもの：腕試しと周回の目的ができる。装備を整えて深さを上げる循環。
- 邪魔にならないか：段0は今と同じ。本体の難易度設定とは別軸（掛け算）。
- 作り方：DreamPressure に段の倍率を足し、送受信は既存の圧の経路。
- 規模：小。試験は Core。

### B3. 縛りの夢（制約つきの遠征）
- 案：「今日の夢」とは別に、週替わりで「縛り」を1つ出す（コモンしか落ちないが強化が2倍速い、確保が3ゾーン目までできない、同じ系統の遺物しか装着できない、など）。達成すると実績と調律石。
- 広がるもの：ふだん使わない装備・型を使う理由。
- 作り方：DailyDream と同じ仕組みで、週の種を使う。
- 規模：縛り 10〜15種。

## C. 協力プレイの役割を増やす

### C1. 絆（特定の旅人どうしの連携）
- 案：固有品・星図の星に「近くに○○（旅人）がいると」の条件（v1.26 の連携は旅人の条件を持てる）。例：Vesper が近くにいると Nachia の召喚獣が防御を得る、Husk と Mist が近いと互いの先制が強くなる。
- 広がるもの：誰と組むかで型が変わる。
- 邪魔にならないか：1人のときは効かないだけ。
- 作り方：連携の条件に「味方の旅人の型名」を足す（いまは自分の旅人だけ）。ホストは参加者の型名を知っている。
- 規模：連携つき固有品 20〜30種。

### C2. 役割の固有効果（前衛・後衛・支援）
- 案：敵に最も近い味方だけに効く／最も遠い味方だけに効く／自分より低HPの味方に効く、などの条件つき効果。「盾役の後ろにいると」「回復役の前に立つと」が成り立つ。
- 作り方：定期走査（0.25秒）で距離と HP を見る。既存の `NearbyEnemies` の走査と同じ。
- 規模：固有効果6〜8個。

## D. 敵側で「型」に意味を持たせる

### D1. 弱点と耐性を持つ変種
- 案：夢の変種に「火に弱い」「障壁を割る」「召喚獣を狙う」「光のスタックを食べる」などの性質。ゾーンの入口で分かるようにする（上部の表示に出す）。
- 広がるもの：ゾーンごとに装備を持ち替える理由（6枠＋保管庫が生きる）。属性・障壁・召喚の型に活躍の場ができる。
- 邪魔にならないか：弱点は「追加で効く」、耐性は「少し効きにくい」までにして、型を否定しない（耐性は −30% まで）。
- 作り方：変種の処理（HostAuthority の monster runtime）の被ダメージ処理で属性を見る。
- 規模：変種 8〜10種（v1.29 の敵側の倍増に含める）。

## E. 集めることを目的にする

### E1. 図鑑の章（固有品・セット・変種・道標の達成）
- 案：図鑑を「章」に分け、章ごとの達成で星図のポイント・工房の枠・称号。
- 作り方：既存の Codex と Feats の拡張。
- 規模：小〜中。
