# v1.31 セットを6部位に（新しい部位と6つ装着の効果の設計表）

利用者の要望（2026-10-04）に基づく設計案。ルールは [v1.31-five-piece-sets.md](v1.31-five-piece-sets.md) の方針（5部位案）を6部位に読み替えて適用した。

## 方針

- 48組すべてに**新しい部位を3つ**足し、武器・頭・鎧・手・足・装飾品の6枠をそろえる。足す部位は、そのセットが持っていない3枠そのもの（既存の3部位の装着枠は [Content.cs](../../src/SodRpg.Core/Game/Content.cs) の `set.<名前>.<枠>` から確認）。
- 新しい部位の土台は、同じ枠の既存の土台から選んだ（新しい土台・新しいアイコンは作らない）。固有効果は2つ。値は `PowerCaps` 以内で、同じ効果が複数あるセットは3つ装着・6つ装着の分を含めた合計も上限以内に収めた。
- **6つ装着の効果**は既存の固有効果1〜2つ。4・5つ装着では新しい効果は付かない（2・3・6の3段階）。3つ装着の効果に上乗せされる。
- 回避で発動する効果（EchoingDodge・Whirlwind・Sprint・ShadowStep・PerfectRead）は新しい部位・6つ装着には使っていない（既存の3つ装着の効果は変更しない）。
- 条件つき攻撃力・魔力の効果の合計は、セット内で覚醒前120%を下回る（ビルド全体の予算は別）。
- 機械可読版: 部位と理由は [tools/set5/sets5.json](../../tools/set5/sets5.json)、通常セット2/3/6点の現行値は [tools/balance/sets.json](../../tools/balance/sets.json)。下記の純ダメージ係数と固定攻撃力・魔力は #119/#121 を反映。
