# v1.31 星のポイントの上限を150→300に（曲線はそのまま、夢の圧の星の係数は半分）

親仕様：`v1.31-star-map-x10.md`（星図を10倍に）。この文書はそのうち「ポイントの上限」と「夢の圧の係数」を担当する。

## 1. 変更の内容となぜか

- `StarProgression.MaxPoints` を **150 → 300** にする。星図が10倍になる分、振れる期間を長くする（v1.30 では約70星の旅人に150ポイントは多すぎ、すぐ取り切れていた）。
- **曲線は変えない**。k 個目のポイントに必要な経験は引き続き `6k + 50`、累計は閉形式 `3n² + 53n`（k=1…300 で成立）。既存の保存にある `StarXp` はそのまま生きて、同じ経験値が新しい上限まで多くのポイントを買う。移行処理・振り直しの強制は不要（予算は増えるだけ）。
- 通信（`Build` の `a:`、`DreamforgePressureMsg`）と保存の形式は変わらない。`a:` の解釈は 0〜300 に切り上げられた上限で切る。プロトコル番号は据え置き（値の範囲が広がるだけで、形式は不変）。
- **夢の圧の星の係数を半分にする**。上限が2倍になったので、そのままでは満額時の圧が2倍になる。`AverageSpentStarPoints` に対する係数を HP 側 `0.005 → 0.0025`、与ダメージ側 `0.0025 → 0.00125` へ。**300振り星は、変更前の150振り星と同じ圧**になる。夢レベルの項（0.025・0.012、5段の無料枠）は触らない。

## 2. 経験の量（150 と 300）

| | 1個目 | 150個目 | 300個目 | 累計（150個目まで） | 累計（300個目まで） |
| --- | --- | --- | --- | --- | --- |
| v1.30（旧） | 56 | 950 | ― | **75,450** | ― |
| v1.31（新） | 56 | 950 | 1,850 | 75,450 | **285,900** |

- 累計は約3.8倍。前半のペース（1個目56・10個目110・50個目350）は完全に同じで、伸びるのは後半だけ。
- 151個目以降の1ポイントは 956〜1,850 経験。獲得ペース自体（通常1・エリート5・ボス20、悪夢は2倍、確保20・踏破100）は変えない。

## 3. 夢の圧の比較（夢レベル30・深度0・道標なし）

| 平均の振り星 | v1.31 のHP倍率 | v1.31 の与ダメージ倍率 | 旧係数のままなら（参考） |
| --- | --- | --- | --- |
| 0 | 1.625 | 1.300 | 1.625 / 1.300 |
| 75 | 1.8125 | 1.394 | 2.000 / 1.488 |
| 150（旧上限） | 2.000 | 1.488 | **2.375 / 1.675** |
| 225 | 2.188 | 1.581 | 2.750 / 1.863 |
| 300（新上限） | **2.375** | **1.675** | 3.125 / 2.050 |

- 旧上限（150星）の圧 2.375 / 1.675 は、新上限（300星）でちょうど同じ値になる。係数を半分にしないと満額時のHP倍率は3.125まで伸びていた。
- 途中の進行度では圧は緩やかになる（150星時 2.375 → 2.000）。星図が10倍になって選択の幅が増える分、同じ星数での圧を少し下げる。
- 深さ・道標・本体の人数補正は従来どおりこの倍率に掛かる（変更なし）。

## 4. 影響範囲

- 上限を `StarProgression.MaxPoints` から動的に読む箇所（Build の `a:` の解釈、夢の圧への平均、UIの進捗表示、予算の検証）は自動的に300へ追従する。
- 価格表示・説明文で「150」を固定値で書いていた箇所は300に置き換えた。
- 現行の木（核＋幹＋橋、容量200〜225ポイント）では300ポイントを振い切れない。10倍の星図（別担当）が入った時点で全旅人が予算を超える容量を持つため、それまでは木の容量の保証は v1.30 の予算（150＋図鑑4）に対して行う。
