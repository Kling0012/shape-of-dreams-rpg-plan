# v1.32 6つ装着の効果のバランス調整（セット48組）

v1.31 で48組すべてのセットに付けた6つ装着の効果を、同じ物差しで測ってやりすぎ・なさすぎを直した記録。変更は [Content.cs](../../src/SodRpg.Core/Game/Content.cs) の `SixPiece` の数値のみ（効果の種類・構成は変えない）。

## まとめ

- 測定の結果、**基準から外れていたのは1組**（`set.wanderblades`、6点ボーナス利得が中央値の0.50倍で「弱すぎ」）。
- `set.wanderblades` の6つ装着の効果「溢れる一撃」を **55 → 90** にした（上限120に対して46%→75%）。6点ボーナス利得は 0.458 → 0.750（中央値比 0.50 → 0.81）。
- ほかの47組は変更していない。調整後に全48組が許容帯（中央値の0.5〜1.5倍）に入り、中央値は 0.925 のまま変わらない。
- 実測の全文は [tools/BalanceSim/result-v1.32-sets-before.md](../../tools/BalanceSim/result-v1.32-sets-before.md)（前）と [tools/BalanceSim/result-v1.32-sets.md](../../tools/BalanceSim/result-v1.32-sets.md)（後）。

## 手法

BalanceSim（tools/BalanceSim）に `--mode sets` を追加し、`SetBalance`（tools/BalanceSim/SetBalance.cs）で次の通り測る。星図・夢・強化・覚醒は介入させず、`Rules.Equip` と `Build.Compute` の実装をそのまま通す。

1. **基準（最良の非セット代替品）**: 6枠それぞれについて、伝説（セット品を除く固有品）とエピックを64個ずつコアの `Loot` で固定シードにより抽選し、その中で代理値が最も高い品を代替品にする。アイテムレベル10、強化・覚醒なし。連携（Link）は常時発動しないので代理値に数えない。
2. **代理値（PowerScore）**: `Build.Compute` が届けた能力値・固有効果を、コア自身の上限（`Content.StatCap` / `Content.PowerCap`）で割って足した「予算の消化率」の合計。Build が上限で抑えた後の値を使うため、3つ装着と重なる6つ装着の効果は上限の内側の分だけ数える。戦闘の出力そのものではなく、コアの上限設計を重さの基準に使う。
3. **計測**: 各組について、登録順の最初の2部位＋代替4枠、3部位＋代替3枠、6部位の3通りを装着して代理値を取り、基準との差を2点・3点・6点の利得とする。6つ装着の効果そのものの利得は、6部位装着の状態で `SixPiece` を一時的に空にした差分として隔離する（計測中のみ `SetDef.SixPiece` を差し替えて必ず戻す。Content の定義は変わらない）。6点占有率は、6点ビルドの代理値に占める6つ装着の効果の割合。
4. **許容帯**: 48組の6点ボーナス利得の中央値（0.925）の0.5〜1.5倍（0.463〜1.388）。中央値比が1.5倍超を「強すぎ」、0.5倍未満を「弱すぎ」とする。
5. **決定性**: 乱数はコアの `Rng`（SplitMix64）を固定シードで呼ぶだけ。同じ Content なら同じ結果になる（同じ補助を使う試験 `SixPieceBalanceV132Tests` がこれを保証する）。

### 仮定と限界

- 代理値は各能力値・固有効果の上限を同価値とみなす。戦闘のシミュレーションではなく、v1.31 の設計が自ら課した上限（`PowerCaps`・`StatCaps`）を物差しに使う。
- 代替品は固定シードで64個ずつ引いた中の最良。「その枠に付きうる理論上の最良」ではない。
- 2点・3点測定の部位は登録順の最初の2つ・3つ。効果の発動はどの部位でも同じため、利得の差は部位そのものの特性（基礎能力・特性の抽選）だけ。
- アイテムレベル10・強化なし・覚醒なし。強化は能力値・固有効果を一様に伸ばすため、相対的な利得の並びはほぼ変わらない。

## 調整の内容

`set.wanderblades`（渡り鳥の剣舞）は6つ装着の効果が「溢れる一撃 55」の1行だけで、上限120に対する消化率が 55/120 = 0.458。中央値 0.925 の0.5倍（0.463）を下回り「弱すぎ」だった。効果の種類は変えずに値だけを上げ、90/120 = 0.750（中央値比 0.81）として帯の中央付近に収めた。3つ装着（渡り鳥 25、会心飛沫 30、戻り刃 15）に溢れる一撃はなく、合計 90 は上限120に届かない。

## 試験

`SixPieceBalanceV132Tests`（tests/SodRpg.Core.Tests/SixPieceBalanceV132Tests.cs）が、この文書と同じ補助 `SetBalance.MeasureAll` で48組を測り、全組の6点ボーナス利得がその場の中央値の0.5〜1.5倍に入っていること、および計測が決定的であること（2回の計測が常に一致すること）を確かめる。Content の `SixPiece` を変更した際はこの試験が帯の外を検知する。
