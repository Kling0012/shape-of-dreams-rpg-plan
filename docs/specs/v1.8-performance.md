# v1.8 仕様：ゲーム全体を軽くする

担当：実装は GPT（OMP 経由）。設定画面の文言・説明と、実機での計測・確認は Claude。

## 背景と調査結果（2026-10-02、逆コンパイル `%LOCALAPPDATA%\sod-decomp\Dew.Core` より）

- 本体はすでに最適化が進んでいて、毎フレーム `FindObjectOfType` を呼ぶような重い処理はほぼ無い。キャッシュによる改善の余地は小さい。
- 本体の設定にある項目（重複させない）：フレーム上限・垂直同期・影の品質・エフェクト品質・テクスチャ・霧・草木・地形・動的解像度・画面の揺れ・ダメージ数字など。
  適用は `DewSave.ApplySettings()` → `ApplyPerSceneSettings()`（設定変更時とシーン読み込みのたびに上書きされる）。
- 本体の設定に**無い**調整（MODで足せる）：
  - 影の**距離**とカスケード数（URP アセット。本体は影の解像度とオン/オフだけを触る。`URPUnlockerAPI.CurrentUnlockedURPAsset` 経由）
  - 追加ライトの1オブジェクトあたりの上限、MSAA、HDR、カメラの後処理（`UniversalAdditionalCameraData.renderPostProcessing`）
  - `QualitySettings.lodBias` / `maximumLODLevel`
  - `Dew.BakeMeshInterval`（スキンメッシュの焼き込み間隔。確認済みの既定値は 0.1 秒。大きくするとCPUが軽くなる）
  - エフェクト品質を本体の「低」より下げること：`GraphicsManager.effectQualityOverride`（public・nullable。Harmony 不要）
  - **ウィンドウが背景にあるときのフレーム制限**：本体には無い。

## 作るもの

`DreamforgeConfig` に次の設定を追加し（MOD設定画面に出る）、新しいファイル `src/SodRpg.Mod/PerformanceTuner.cs` で適用する。

1. `backgroundFps`（整数、既定 20、0 で無効、有効値は20〜60。範囲外は0〜60へ制限し、1〜19は20へ補正）
   - `OnApplicationFocus(false)` で現在の `Application.targetFrameRate` と `QualitySettings.vSyncCount` を覚え、`vSyncCount = 0`、`targetFrameRate = backgroundFps` にする。
   - 戻ったら本体の `FPSManager.UpdateFPSLimit()`（`ManagerBase<FPSManager>.softInstance` 経由）を呼んで本体の設定に戻す。無ければ覚えた値に戻す。
   - Mirror のホストを止めないため `Application.runInBackground` は変えない。20未満は設定できないようにする（ホストの30Hz処理が粗くなるため。0=無効は可）。
2. `lightweight`（列挙：`Off` 既定 / `Light` / `Strong`）
   - **Light**：影の距離を初回適用前の値の 0.6 倍、カスケードを最大2、追加ライトの1オブジェクト上限を最大2、`lodBias` を 0.7 倍、`BakeMeshInterval` を 0.15 秒（Claude の決定）。
   - **Strong**：Light に加えて、影の距離 0.4 倍・カスケード1、`effectQualityOverride` を本体の最低品質、確認済みの URP アセット API で MSAA オフ、`lodBias` 0.5 倍、`BakeMeshInterval` を 0.2 秒（Claude の決定）。
     （後処理のオフと描画解像度の固定は見た目が大きく変わるので今回は入れない）
   - `Off` に戻したら、MODが変える前の値（初回適用時に保存）にすべて戻す。
   - 本体が上書きするので、`DewSave` の設定変更通知と `SceneManager.sceneLoaded` のあとに再適用する。毎フレームは何もしない。
3. 計測：`perf.flag` のログ（DreamforgeMod の PerfMeter）の行末に、現在の `lightweight` と背景中かどうかを付ける。

## 守ること

- 見た目・描画だけを変え、ゲームの進行や同期に関わる値（乱数を使う処理、`FxNetworkedEffect`、ホストのロジック）は触らない。
- 本体の型・メンバー名は `D:\app\stm\steamapps\common\Shape of Dreams\Shape of Dreams_Data\Managed` の DLL と逆コンパイル結果で必ず確かめる。存在しない・例外が出る場合は、その項目だけ飛ばしてログに1回だけ書く（落とさない）。
- 本体のマネージャーは `.softInstance` で参照する（`.instance` は不在時に毎回 `FindObjectOfType` を走らせる）。
- 毎フレームの処理やメモリ確保を増やさない。
- 試験（tests/）は追加・変更しない。設定項目の表示名・説明文は仮の英語でよい（Claude が日本語を書く）。
- `dotnet build src/SodRpg.Mod -c Release -p:GameDir="D:\app\stm\steamapps\common\Shape of Dreams" -p:ModDeployDir="<作業フォルダ>\deploy"` で通ること（ゲームのフォルダへは書き込まない）。

## 実装と検証の引き継ぎ

- `PerformanceTuner` は設定変更・シーン読込・フォーカス変更で動作し、`Update` は持たない。元値は対象アセット／マネージャーごとに保存し、Strong→LightではStrong専用項目を、Off／アンロードでは変更項目を復元する。
- `Shadows` のラッパーはアセットごとに保持する。APIアクセスは項目ごとに例外を捕捉し、警告は項目ごとに一度だけ出す。
- `perf.flag` と `dreamforge_perf` の出力末尾に `lightweight` と `background` を追加する。
- `GameRef` に `inc8877.GraphicsConfigurator`、`Unity.RenderPipelines.Universal.Runtime`、`Unity.RenderPipelines.Core.Runtime` を追加する。
- この実装環境はコマンド実行禁止のため、ビルド・テスト・実機確認・コミットは未実施。Claude が Light／Strong／Off、設定変更とシーン遷移、背景／復帰、背景中の無効化とFPS変更、MODアンロード時の復元を確認する。

## 追加：最上段「Max」（2026-10-02、計測結果から Claude が決定）

計測では「強め」でも4〜6%の改善にとどまった。一方、描画解像度はフレーム時間を大きく左右した（解像度2倍で 5.6ms → 7.0ms）。
そこで、見た目より軽さを優先したい人向けに `LightweightMode.Max = 3` を追加する。

- Max = Strong の全項目 ＋ URP アセットの `Quality.RenderScale` を、初回適用前の値の 0.75 倍にする（下限 0.5）。
- Max 以外に戻したら `RenderScale` を元に戻す。
- 確認用コマンド `dreamforge_lightweight` は 0〜3 を受け付ける。
