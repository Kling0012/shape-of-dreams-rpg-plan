# v1.27.1「回復量・シールド量・召喚獣・HP を捧げる量」

利用者の指示（2026-10-03）：回復量・シールド量・召喚獣・HP を捧げる量を伸ばす効果を入れる。v1.27.1 として出す。

v1.27 のレビューで、Nachia（回復・シールド・召喚獣）、Aurena（回復・HP を捧げる）、Cetus（シールド）の固有星座と合わせるのに、これらの値が足りないと分かった。

| 能力値 | 意味 | 上限 | 本体での当て先（ホスト） |
| --- | --- | ---: | --- |
| 回復量 `HealPower` | その旅人が与える回復 +X%（味方への回復も） | 60 | `Actor.dealtHealProcessor`（`HealData.ApplyAmplification`） |

- MOD 自身の回復・障壁（吸収・魂喰い・護りの灯・溢れる命など）にも、回復量・シールド量を掛ける（説明文と動きをそろえる）。
- 説明文：「与える回復が X% 増える（味方への回復も）」「与えるシールドが X% 増える（味方へのシールドも）」「召喚獣の与えるダメージが X% 増える」「HP を捧げる技の消費が X% 減る」。上限は説明に書く。
- 送受信：装備の文字列の能力値として送る（通信の版は5のまま。新しい値が読めない古い版とは、もともと版5どうしでしか遊べない）。
- 本体の API は型の一覧で確かめる。足りなければ逆コンパイル（読むだけ）で確かめ、確かめた場所を残す。実機での確認は未確認と書く。

## どこで手に入るか

- **星図**：Nachia・Aurena・Cetus（必要なら Vesper のシールド、Bismuth の障壁）の記憶ルートと核で、いまの能力値の星のうち合わないものを置き換える。各記憶の仕組みに合うもの（回復を与える記憶には回復量、シールドを張る記憶にはシールド量、召喚の記憶には召喚獣の力、HP を捧げる記憶には軽減）。旅人ごとの合計は上限の8割まで。
- **装備の特性**：アクセサリー・鎧・頭に、回復量・シールド量を低い重みで足す（レア度に応じた値）。召喚獣の力と捧げる量の軽減は、星図と固有品だけにする。
- **固有品**：回復・シールド・召喚・HP を捧げることを題材にした固有品を 12 種ほど足す（Nachia・Aurena・Cetus の記憶や本体の固有星座と噛み合うもの）。

## 実装記録

- `Stat` の既存番号は変更せず、20～23 に4能力値を追加。通信の版は5のまま、既存の装備文字列で送受信する。能力値補正 `StatBonus` には渡さず、ホストの戦闘処理で適用する。
- `SupportStats` に倍率計算を集約。負の強化量は0、上限を超えた強化量は各上限として扱う。回復・シールド・召喚ダメージは本体の増幅処理、HP消費は元の消費ダメージへの倍率として適用する。
- 回復・シールドは旅人に処理を一度だけ登録する。本体が発生元の親をたどるため、味方への効果とMOD自身の吸収・魂喰い・護りの灯・溢れる命なども同じ経路を通る。各効果の呼び出し側では重ねて倍率を掛けない。
- 召喚獣は生成通知と親旅人から登録し、装備情報の到着前に存在した召喚獣も拾う。発生元に最も近い召喚獣だけが倍率を掛け、召喚獣がさらに召喚した場合の二重適用を防ぐ。装備変更は現在の構成を参照し、召喚獣の消滅・旅人の解除時に登録を外す。
- HP消費は `Se_HealthCost`、ゴールデンバースト、還元の確認済み自己消費だけを対象にする。敵への攻撃や通常の被ダメージには適用しない。本体の固有星座による軽減・消費なし・生存用の消費制限を残し、その後の消費に乗算する。本体の発動可否判定と消費予告表示は変更しない。
