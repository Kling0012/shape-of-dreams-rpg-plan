## 仕組み

固有品（`UniqueDef`）に「連携」を1つ持たせる。連携先は本体の記憶・エッセンスの型名（例：`St_L_Blizzard`、`Gem_L_Perfect`、`St_D_DoubleTap`）。

| 連携の種類 | 効果（X は値） | 判定に使う本体の仕組み |
| --- | --- | --- |
| 記憶加速 MemoryHaste | 連携先の記憶を使うと、そのクールダウンが X% 早く戻る | スキル使用の通知（使った記憶の型名）と、クールダウンの割合短縮 |
| 記憶の余韻 MemorySurge | 連携先の記憶を使った後の5秒間、攻撃力・魔力 +X% | 同上と、時限の能力値 |
| エッセンス同調 EssenceAttune | 連携先のエッセンスを装着している間、攻撃力・魔力 +X% | 装着中のエッセンスの一覧（定期の走査） |
| エッセンスの守り EssenceGuard | 連携先のエッセンスを装着している間、最大HP +X%・防御 +X | 同上 |

- 連携の効果は、固有品の2つの固有効果に加わる。1つの連携先に固有品1つ（計107種）。
- 能力の送受信（Build）に連携を足す。通信の版を4に上げる。
- 画面：遺物の詳細に「連携：『吹雪』を使うと…」と、連携先の名前（本体の日本語名）と効果を出す。連携先を装着していなければ灰色で「（装着していません）」。
