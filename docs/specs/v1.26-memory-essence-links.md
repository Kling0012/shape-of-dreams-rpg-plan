# v1.26「記憶・エッセンス・旅人に連携する固有品」

利用者の要望（2026-10-02）：
- 各旅人の各種類の旅人記憶、レジェンダリーの各記憶、レジェンダリー・ユニークの各エッセンスに連携する効果を持つものを追加したい。
- 同じ発想で、特定の2つの記憶を組み合わせて持てたときだけ大きな効果を発揮するもの、特定の旅人と組み合わせたとき、特定の旅人とエッセンスを組み合わせたときなど、樹形図で全パターンに対応する。
- 旅人記憶が複数あることを忘れない。
- 記憶とエッセンスは多すぎるので、**レジェンダリー以上はすべて必須**。それ以外は面白そうなものがあれば。

## 連携先（本体の RawData で確認）

| 種類 | 数 | 扱い |
| --- | ---: | --- |
| レジェンダリーの記憶 | 10 | 必須 |
| ユニークの記憶 | 7 | 必須 |
| レジェンダリーのエッセンス | 14 | 必須 |
| ユニークのエッセンス（導きの羅針盤は充電前後を1つに） | 5 | 必須 |
| 旅人（本体の9人） | 9 | 組み合わせの条件として使う |
| 旅人の記憶（Character・Identity。旅人ごとに6〜7、共通8） | 71 | 面白い組み合わせを選んで使う |

## 条件の樹形図（「必要なもの」をすべて満たしたときに効く）

```
連携の条件
├─ 単体（1つ）
│  ├─ 記憶 …………… その記憶を装着している
│  ├─ エッセンス ……… そのエッセンスを装着している
│  └─ 旅人 …………… その旅人で遊んでいる
├─ 2つの組み合わせ（大きな効果）
│  ├─ 記憶 × 記憶
│  ├─ 記憶 × エッセンス
│  ├─ エッセンス × エッセンス
│  ├─ 旅人 × 記憶（その旅人の旅人記憶、または共通の記憶）
│  └─ 旅人 × エッセンス
└─ 3つの組み合わせ（とても大きな効果）
   ├─ 旅人 × 記憶 × エッセンス
   ├─ 旅人 × 旅人記憶 × 旅人記憶（旅人記憶が複数あることを生かす）
   ├─ 記憶 × 記憶 × エッセンス
   └─ 記憶 × エッセンス × エッセンス
```

## 効果の種類

| 種類 | 効果（X は値） | 条件に記憶が要るか |
| --- | --- | --- |
| 記憶加速 MemoryHaste | 条件の記憶を使うと、そのクールダウンが X% 早く戻る | 要る |
| 記憶の余韻 MemorySurge | 条件の記憶を使った後の5秒間、攻撃力・魔力 +X% | 要る |
| 同調 Attune | 条件を満たしている間、攻撃力・魔力 +X% | 要らない |
| 守り Guard | 条件を満たしている間、最大HP +X%・防御 +X | 要らない |

上限は、条件の数で大きくする。単体：同調・守り 25、記憶加速 50、記憶の余韻 40。2つ：それぞれ 1.6倍。3つ：それぞれ 2.2倍。

- 本体の旅人9人は、それぞれ「旅人×旅人記憶」「旅人×旅人記憶×旅人記憶」の組み合わせを1つ以上持つ。
