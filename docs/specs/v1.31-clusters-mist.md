# v1.31 ミストの星団案 — 命中から構え直す剣

対象は `Hero_Mist`。2026-10-03 に指定された仕様・C#・日本語 RawData を読み合わせた設計であり、実装済みを意味しない。**725個の取得可能な星**を定義する。始まりの表示点は数に含めない。全体能力値だけの星は既存星の移行後も **0個**。既存ID、既存の段数、エッセンス枠3個は保持する。

## 表の展開規則と効果の契約

新星は全て **1段・1ポイント**。同じ記号を複数のIDに展開したものは別の取得星だが、二択の選択肢は星数に加えない。小さな星は大きな効果へ至る支出であり、取得した時点から表の値だけ実際に効く。どの表も省略されたランダム効果・汎用代替・空の接続点を含まない。

|記号|星の種類と1段の値|
|---|---|
|`D(m,x)`|`MemoryDamage(m,+x%)`。m由来の本体ダメージだけ。基本攻撃全般、エッセンス、仕掛け、属性反応は対象外|
|`B(m,x)`|`GimmickBoost(m,+x%)`。そのmに帰属する取得済み仕掛けのValueへ加算倍率。新機構M1。確率もValueの意味を守る。Reloadの回数、Dazeの時間、持続秒数、半径、Argには掛けない|
|`H(FF,x)`|`MemoryHaste(FF,x%)`。FFだけのCD計算倍率へ `1-x/100`。新機構M3。回避の使用通知では発動させない|
|`P(m,p,x)`|`GimmickParam(m,p,x)`。Durationは秒数への+%、Radiusはmへの+%、Chanceは確率への+%ポイント、ExtraTargetsは対象数への加算。適用対象の効果を表の通り限定する|
|`G(m,t,e,v,a,c)`|Notable。`GimmickDef{Trigger=t,Effect=e,Value=v,Arg=a,Cooldown=c}` をmに付ける。表では `t:e v/a/c` と短縮。mはその行の記憶、tは `Hit=OnHit, Kill=OnKill, Use=OnUse`|
|`R(m,t,x→FF)`|Notable。mのtで `GimmickDef{t,Recharge,x,0,0}`、受け手だけFF。既存ペアの `RechargeMemory` と同じ対象指定を単独Notableへ広げるM2|
|`C[A ∣ B]`|Choice。ちょうど2つの実効果から1つ。両方を同時取得しない。変更時は旧効果を外してから新効果を登録|

`B` の入口は、その記憶の既存 `.2` と `.4` のうち少なくとも1星を必要とする。両方未取得のままBへ迂回できない。FLのReloadだけを取ってBを取得できる経路は設けない。`P` は表の対象Notable取得が必須。外したときに依存星を残せない。IdentityにHを置かず、FFにD・自身起点のGを置かない。

M1では百分率を固定小数点で合算し、最終ダメージ・回復・障壁へ小数を保持して適用する。例えばShield 1%へB+2%は最大HPの1.02%であり、intへ丸めて1%に戻さない。Hの0.25%も同じ精度で保持する。**新星のD総量は1記憶につき80%以内、旧Dと合わせて120%以内、B総量は+200%以内、FFのHは40%以内**となるよう、全取得時の値を末尾で検算した。取得禁止で空効果を隠さない。既存の `Links.EquippedCap` に新星を詰めて黙って丸めることは禁止し、既存装備の連携とは別の星図用集計枠にする。Gimmicks.Capは効果そのものの上限として保持する。

|既存効果|正確な意味・重複上限|
|---|---|
|Echo|当てた最終ダメージのValue%を0.3秒後にPureDamageで1回。死んだ敵には当たらない。Value上限1000%|
|Burst|発動位置の周囲4mへ攻撃力/魔力の高い方のValue%。高い方が魔力なら魔法、同値なら物理。Value上限1000%|
|Shield / Heal|最大HPのValue%。Shieldは4秒、Heal Arg1は自分と10m内の味方旅人。Value上限100%。別星のShieldは本体の障壁へ加算される。有限の総量をM4で管理|
|Expose / Sap|命中した敵への4秒窓。Exposeは自分の与ダメージ+Value%、Sapは敵の与ダメージ−Value%（ボス/ミニボスは半分）。各効果は同時最大値1つ、弱い値を加算しない。上限100% / 15%|
|Wound|3秒かけて攻撃力/魔力の高い方のValue%。同じ敵では最大値1つ、強い方の毎秒量を保持して更新。上限120%|
|Element|Arg 0火/1冷気/2光/3闇。Value100ごとに1スタック、残りは追加1スタックの確率。1要求上限600、敵上限は火なし・冷気1・光5・闇5。既存スタックを消費しない|
|ElementEdge|命中時に既にある属性の種類を読む。1種類ごと攻撃力/魔力の高い方のValue%、最大4種類・合計160%。1種類のValue上限40%。スタックを消費しない|
|Recharge / RechargeOther|前者は指定記憶の残りCDのValue%短縮。後者は装備した他の通常記憶へ適用し、Identity・Movement・実際のUltimateを除外。両者Value上限100%。本体の短縮不可を尊重|
|Ricochet|命中の最終ダメージのValue%を8m内の別の敵Arg体へ。Value上限50%、Arg最大2。既存の最小間隔0.3秒を保持。継続電撃や多数への刺突から全体数が二乗に増えるのを抑えるため|
|Primed|現行は全記憶で1つの準備量・5秒まで、Value上限120%。別種類の次攻撃上乗せとは最大値1つだけを使い、他の種類は消費しない。本案の記憶別の保持と5.5秒化は新機構M8であり現行実装のままでは成立しない|

表で使わない効果も確認済み：Quicken/Empowerは4秒・同時最大値1つ、Reloadは最大1回、DazeはValue/10秒・最大0.8秒で同一敵5秒、Siphonは直接ダメージから最大HP1.5%までで最小間隔0.5秒、Rampartは同一発動の別敵最大5体・障壁最大10%・同時最大1つ、Crescendoは同一発動1回・最大5重/40%・記憶の冴えとの合計120%、PackMendは生存する自分の召喚獣だけ、Weakspotは対象限定会心率最大25%。本案はこれらの汎用会心・加速・吸血の上位版を増やさない。

仕掛けの追加ダメージは全て無属性・攻撃効果強度0・再発動なし。回復と障壁は `ActorManager.instance.serverActor` から付与する。新たな回避・ダッシュ・テレポート起点は0件。LUの前方回避やFLの突進も発動条件にせず、**その記憶の本体ダメージの命中/撃破**だけを使う。
