# 遠征の鍛錬の対象変更

2026-10-18の利用者決定により、遠征の鍛錬をタンク役のヴェスパーとケトゥスだけに残した。2人の星・値・配置は変更していない。

- 削除した星は、`aurena`・`bismuth`・`husk`・`lacerta`・`mist`・`nachia`・`yubar` の各 `<hero>.run.g1`・`<hero>.run.m1`・`<hero>.run.m2`・`<hero>.run.choice`。合計28星をmanifestと鍛錬の数値表から外し、7人分だけ配置を生成し直した。
- 取得済みの削除星は改訂3の移行で外す。各星は1段・費用1ポイントなので、1人につき最大4ポイントを全額戻す。追加ポイントを増やさず、使用済み費用を解放する。お知らせは既存の移行方式と同じく旅人ごとにまとめ、移行後の保存や同じ改訂を通知済みの途中再開では繰り返さない。空殻の既存改訂2は保持する。
- 途中再開の鍛錬記録と旧版から届く通信は、削除した28IDの記録だけを捨てて読み込む。旧版の星割り当てと使用ポイント数も受け付け、現在の定義で効果を計算し直す。タンク2人の記録と鍛錬の仕組み、保存・通信形式は保持する。
- 確認済み：manifestと数値の生成一致、全9人の配置検査、対象外の定義・値とタンク2人の配置の不変、Core・Native・Startupの関連既存テスト、MOD Releaseビルド、WikiGen生成、BalanceSimの最小実行。WikiGenでは星図とは別の`sets.txt`にサイズ超過警告が出た。
- 未実行：ゲーム内の確認（この環境では起動不可）、全体・低速テスト（関連する既存テストだけを実行する指定）、旧セーブと旧通信を使った今回の互換分岐の直接確認。net8.0の検証は.NET 8ランタイムがないため.NET 10へのロールフォワードで実行した。
