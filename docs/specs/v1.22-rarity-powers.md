# v1.22「レア度にふさわしい固有効果」

利用者の助言（2026-10-02）：レア度が高い装備品は、それなりのユニーク効果があってもよい。

## いま（v1.21）

| レア度 | 固有効果 | 名前 |
| --- | --- | --- |
| コモン | なし | 土台の名前 |
| アンコモン | なし | 土台の名前 |
| レア | なし | 土台の名前 |
| エピック | 1つ（その枠の候補から、範囲の中でランダム） | 土台の名前 |
| 伝説（固有品） | 2つ（決まった組み合わせ） | 固有の名前と言い伝え |

レアは数値だけで、エピックも「固有効果が1つ付いたレア」に近く、手に入れたときの特別感が薄い。

## 変更

| レア度 | 固有効果 | 名前 |
| --- | --- | --- |
| レア | **1つ（弱め：その枠の範囲の下半分）** | 土台の名前 |
| エピック | **2つ（1つは範囲どおり、もう1つは下半分。同じ固有効果は出ない）** | **銘が付く**（例：「烈火の 連なりの剣」） |
| 伝説 | 2つ（変わらず） | 変わらず |

- エピックの「銘」は、1つ目の固有効果から決まる短い言葉（30種の固有効果それぞれに1つ）。一覧と詳細で、土台の名前の前に出す。
- 強化+5の節目：固有効果を持つ遺物は特性が1行増える（v1.20 のまま）。レアも固有効果を持つので、+5では特性が増える。
- すでに持っている遺物は変わらない（新しく手に入れた物から）。
- 合計の上限（`PowerCaps`）はこれまでどおり。

## ねらい

- レア：数値に小さな「くせ」が付き、拾うたびに組み合わせを考える余地ができる。
- エピック：銘と2つの固有効果で「当たり」と分かる。伝説との間をつなぐ。
- 伝説：決まった組み合わせと言い伝え・覚醒で、いちばん特別なまま。

## アイテム数も増やす（利用者の助言：アイテム数はできるだけ増やそう）

- 新しい枠（頭・手・足）を使うセットを12種追加する（3部位ずつ、計36部位）。セットは 12→24 種、固有品は 298→334 種。
- セットの組み合わせ：頭・手・足の3部位のもの、主装備＋手＋装飾品のように新旧の枠をまたぐもの。2点・3点の効果は、既存のセットと重ならないようにする。
