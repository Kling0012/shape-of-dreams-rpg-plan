# v2.12 ケトゥスの強化（火力と耐久）

利用者の依頼（2026-10-09）：「ケトゥス 強化依頼」。背景の補足：ミストや空殻は、速くて強い攻撃とドレインでタンク以上の耐久が出せてしまうため、タンクのケトゥスは火力も耐久も弱く見える。
夢の圧の引き上げ（v2.11：敵HP最大×16.5・敵の数×5・与ダメージ×3.4）の後で、ケトゥスが耐えて倒しきれる水準にそろえる。

星の依存関係と座標は変えない（別スレッドで調整中）。数値原本 `tools/balance/stars.json` のセルだけを変え、`python tools/balance/gen_cs.py` で生成した。星のID・段数・費用・保存形式・Protocol は変えない。

## 1. 比較で見えた弱点

| 観点 | ケトゥス | 比較（ミスト・空殻ほか） |
| --- | --- | --- |
| 記憶の冴え（主力記憶の合計） | 約224%（6記憶） | 空殻 約1,060%、ミスト 約830%、ユバール 約530% |
| 攻撃の仕掛け（Burst＋Echo＋Wound＋属性刃）の値の合計 | 約441 | ミスト 約699、空殻 約626 |
| 刻印の上乗せ | 「遠い潮路」＋20%、「集束する雷」＋45%、「拳の誓い」＋60% | 他の旅人の同種は＋40〜100%、単独記憶なら＋80〜100%が中心 |
| 旧版からの橋（夢輪）の再充填 | 3〜4本が低い段（10/20/30%・10/15/20%）で、30/40/50%の段がない | 他の8人は全員30/40/50%の橋を持つ |
| 守りの仕掛け | 盾・回復・防壁は1〜3%の小粒 | 速く殴るミスト・空殻は命中・撃破ごとの回数で稼ぎ、装備のドレインも乗る |
| 能力値 | v1.31で防御系の能力値の星が仕掛けの強化に置き換わり、ケトゥス固有で残るのは外周の「深海の殻」「殻の厚み」だけ（HP＋2%・防御＋2） | 防御を能力値の星で補う手段がほぼない（装備のドレインで補うミスト・空殻との差） |

ミスト・空殻は1回ごとの回復量が小さくても、攻撃の回数で耐久を出せる。回数で勝てないケトゥスは、1回あたりの盾・回復と、技（スタン）で張り直す盾を厚くして差を埋める。

## 3. 変えないもの

- 星の依存関係・座標・費用・段数・ID。
- 他の旅人の値。夢の圧、装備、セット。
- 実行時の上限（盾は最大HPの15%まで、防壁は1回2%・合計10%、Echo/Burstは1000%など）。上限に当たった分は増えない。

## 4. 確認

- 計算とテストで確認した。実機での手応え（ミスト・空殻との比較、敵が5倍に並んだときの耐久）は未確認。
- やりすぎの場合は `stars.json` のセルを戻し、`python tools/balance/gen_cs.py` で再生成するだけで戻せる。
- 内容の指紋が変わる。協力プレイでは全員が更新する。
