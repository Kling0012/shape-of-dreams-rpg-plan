# v1.29 固有品・セットの取り込み保留（パス2）

`docs/specs/v1.29-uniques-table.md` の固有品559・セット24のうち、パス1で取り込まなかった行の一覧。パス1で入れたのは、両方の効果が既存の効果（`Power` enum）か属性の反応4つ（蒸気・蝕・燃え殻・氷晶）で組まれた固有品52個（連携つき8個）と、3点効果が同条件のセット4種（部位12個）。
