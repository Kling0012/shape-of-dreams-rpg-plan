# v1.28「装備の%を控えめに」と保存の issue #16・#17

## 装備の%（利用者の指示、2026-10-03）
アンコモンやレアくらいのレア度で、攻撃力や魔力が%で増えるのは過剰。%による向上は全体に控えめにする。

いま：攻撃力%・魔力%の特性は元の値 4〜8 に、アイテムレベルの倍率（最大2.17倍）とレア度の倍率が掛かり、アンコモンでも1行で最大約17%、伝説で強化を重ねると40%を超える。ほかの%の能力値も同じようにレベルで伸びる。

変更：
- **攻撃力・魔力の固定値**（`AttackFlat`・`PowerFlat`。本体の `attackDamageFlat`・`abilityPowerFlat`）を足す。特性の元の値 2〜5、アイテムレベルとレア度で伸びる。上限 150。
- 攻撃力%・魔力%の特性は**エピック以上だけ**に付く。元の値 2〜4。コモン〜レアは固定値を引く。
- **%の能力値はアイテムレベルで伸びない**（攻撃力%・魔力%・攻撃速度・会心・会心ダメージ・最大HP%・移動速度・射程・属性の増幅・回復量・シールド量・召喚獣の力・捧げる量の軽減）。レベルで伸びるのは固定値（攻撃力・魔力・最大HP・防御・HP回復・記憶加速・行動妨害耐性）だけ。レア度と強化の倍率は今までどおり掛かる。
- 土台（装備の種類）の基礎能力が攻撃力%・魔力%のものは、同じ値の固定値にする。
- 攻撃力%・魔力%の合計の上限 120 → 60。
- 星図の%（旅人の成長）はそのまま。
- アップデートノートには「%の伸びを控えめにし、攻撃力・魔力の固定値を足した」と書く。

## issue #16：リセット後の初回保存の直後に読み直すと、旧版の .bak が選ばれる
- 読み込みで、版が `ResetBeforeVersion` より古い保存は、バックアップからの復旧の候補にしない（本体が読めて版2なら本体、本体が読めなければ版2の .bak だけを使う）。
- 試験：版1・rev 42 からリセット → 1回保存 → 読み直しで新しい進行が残る。本体が壊れていて .bak が版1なら、旧進行を復活させず新しいプロフィールとして始め、知らせる。

## issue #17：写しを作れなかったあとも保存でき、旧データが失われる
- リセットに必要な写し（本体と .bak の両方）がそろうまで、**保存を止める**（`ProfileStore` が書き込みを拒否し、画面に保存の失敗として出す）。次の起動でもう一度写しとリセットを試す。
- 2つ目の写しだけ失敗したときも同じ（1つ目の写しは残す）。
- 試験：それぞれの写しに失敗を入れたあと保存を試みても元のファイルは変わらない。I/O が戻った次の起動で正しくリセットされる。

## データのリセット（利用者の指示、2026-10-03）
装備の変更が大きいので、v1.28 でもすべてのデータをリセットする。保存の版を 2 → 3（`ResetBeforeVersion` も 3）。版2以前の保存は写しを残して新しく始める（v1.27 と同じ。#16・#17 の直しを含む）。
