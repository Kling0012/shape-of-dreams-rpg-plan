# 刻印を最大3つまで（設計）

星のレベル（星の経験で得たポイント。上限500）に応じて、同時に選べる刻印の数が増える。

| 星のレベル | 刻印の枠 |
| --- | --- |
| 0〜199 | 1 |
| 200〜399 | 2 |
| 400〜 | 3 |

- 各刻印の条件（つながり・系統の段数・熟練度）と費用は今のまま。同じ刻印は重ねて選べない。
- 枠が減る（星のレベルが下がることは通常ないが、データの都合で減った）場合は、後から選んだ刻印から外し、費用を戻す。
- 刻印の代償で既に振った星が効かなくなる場合は、今と同じく一覧を見せて承認後に払い戻す（C15）。2つ目・3つ目でも同じ。
- 保存：`keystone`（1つ目）はそのまま残し、2つ目以降を任意キー `keystones` に持つ。古い保存は1つのまま読める。保存形式の版は上げない。
- 通信：ビルドに選んだ刻印をすべて載せる。協力プレイの版（Protocol）を1つ上げる。
- 画面：刻印の帯に「刻印 n/枠数」を出し、選択済みの刻印を外す操作と、次の枠が開く星のレベルを表示する。
