# 夢の深さと道標の戦闘処理 / Dream depth and waypoint combat

## 夢の深さ / Dream depth

遠征を始める前にホストが0〜5を選ぶ。プロフィールの前回の選択と、進行中の遠征の深さは別に保存する。遠征中の値は固定し、協力プレイではホストの選択を共有する。既存の潜行の熱、開始深度の旧フィールド、本体のLimbo深度とは独立する。

The host chooses a depth from 0 to 5 before the expedition. The remembered preference and the active expedition's depth are stored separately. Depth stays fixed for that expedition and is shared with the party; it is independent of delve heat and native Limbo depth.

| 補正 / Modifier | 深さ d による倍率・加算 / Formula |
| --- | --- |
| 敵の最大HP / Enemy maximum health | ×(1 + 0.15d) |
| 敵の与ダメージ / Enemy damage | ×(1 + 0.08d) |
| レア度の幸運 / Rarity luck | +0.25d |
| 覚醒の力 / Awakening points | ×(1 + 0.25d) |
| 星の経験 / Star experience | ×(1 + 0.2d) |

敵の倍率は、参加者の夢のレベルと使用済み星ポイントから求めた夢の圧に掛ける。道標が夢の圧を変える場合は、その倍率も掛ける。人数による本体の補正は変更しない。整数の報酬は、すべての倍率を掛けた後に一度だけ四捨五入する。深さ0は従来と同じ。

Enemy multipliers apply after the existing pressure calculation from the party's average dream level and spent star points. A waypoint's pressure multiplier also multiplies that result. Native multiplayer scaling remains intact. Integer rewards round once after combining multipliers, with halves rounded upward. Depth zero preserves the existing behavior.

## 道標の適用先 / Waypoint application

- 回復と障壁は、旅人の受け手側の処理で倍率を掛ける。味方からの効果と、仕掛け・氷晶が使う独立した送り手からの効果にも適用する。自然回復の能力値そのものは変えない。
- 召喚の道標は、実際の召喚獣が与えるダメージに掛ける。子の召喚獣からのダメージを親でもう一度増幅しない。旅人の最大HPの代償は最終能力値に掛け、終了時に取り除く。
- 記憶の道標は通常記憶の使用後に残りクールダウンを20%短縮する。移動・アイデンティティ・Ultimateは対象外。本体の短縮不可設定を尊重する。複数設定を持つ記憶は、本体の短縮APIと同じく現在設定から求めた比率を各設定へ渡す。
- 「悪夢狩り」は、悪夢化の抽選を増やし、悪夢化した敵の戦利品を増やす。新しい敵を生成したり本体のエリート数を変えたりはしない。潜行の熱が0でも抽選できるよう、その道標だけ最低1段の抽選を使う。
- 「明けない夜」は各敵に悪夢の性質を1つ付ける。そのゾーンでは夢の変種の抽選に代えて悪夢化を使い、複数の追加システムによる重なりを抑える。敵の生成待ちの処理はホストの確保地点での選択が終わるまで待つ。

Healing and shielding multipliers run on the recipient, including allied and isolated server-actor effects; passive regeneration stats are unchanged. Summon damage is amplified once at the nearest summon ancestor. The hero health cost multiplies final maximum health. Normal memory cooldowns are shortened after use while native opt-outs and excluded skill categories remain intact. Nightmare Hunt increases nightmare selection and nightmare loot rather than spawning enemies. Endless Night gives each enemy one nightmare trait in place of variant selection. Pending monster processing waits for the host's secure-point decision.

確保地点の選択を残して戦闘へ進んだ場合は、選択中の道標（未選択なら道標なし）を確定し、契約を追加せずに潜行する。ホストは旅人の対敵ダメージ処理でもこれを確定し、選択中の道標が最初の撃破に間に合うよう待機中の敵を処理する。協力プレイで共有選択の通知がまだ届いていない撃破は、敵オブジェクトを保持せず報酬に必要な値だけを待機させる。

Continuing into combat with an unresolved secure-point choice commits the selected waypoint, or none, and delves without adding a pact. The host also resolves this from the hero's damage processing so pending monster modifiers are applied before the first kill. Kills awaiting the host's shared choice retain only reward facts, not references to game entities.
