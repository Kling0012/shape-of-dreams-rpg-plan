# v1.31 effect-wiring fixes

1. StillWater: moved from the status-added event (too early, basic effects not yet added) to a Harmony patch on `EntityStatus.AddBasicEffect` (`HostAuthority.StillWater.cs`). Fires once per real `StunEffect` that the hero's own skill applies to an enemy; cooldown/value unchanged (`TakeStillWater`). The old `OnEnemyStatusAdded` hook was removed.
2. Finale: `TakeFinale` fraction is now converted with `ReduceNormalMemory` (percent of the remaining cooldown), like other cooldown powers.
3. Overload: `OnSkillUsed` takes `isIdentity`; Identity, Movement and Ultimate no longer start it (Q/W/E only). `Ids.cs` comment updated.
4. Retaliation: `OnDamaged(..., attackedByEnemy)`; the host passes whether the damage source's first entity is an enemy. Self/ally damage no longer triggers it.
5. StarOffering: uses `AddStarXp` (dream-depth multiplier applies; star-point notice comes from the wrapper).
6. Pact curse: `PactCurseSync` (Core). Client tick `TickCurseResync` re-sends the curses of persisted pacts once per run/hero/host-authority key (the Delve send marks the key as done). The ordinal rides in the high bits of `strength` (no wire change). Host `OnCurse` applies a resync curse only if fewer than `ordinal` live pact curses exist (`OwnedEffectRegistry.CountLive`), so it is idempotent per player.
7. Dream-depth rooms: `DreamDepth.ZoneNodeOffsetForGeneration` uses the host's chosen depth when no run exists yet and the zone index is 0 (first zone of a new game).
8. Pair combo RechargeOther text: now describes all other normal Q/W/E memories (excluding Movement, Ultimate, Identity and the triggering memory).
9. Armored variant text: "memory以外のダメージ" wording (JA/EN), tag notice renamed (記憶以外に堅い / non-memory-armored); the weakness-keyword test was updated.
10. DeathBurst: text says about 20% of max HP, scaled by dream pressure and delve.
11. Elder Treant: text says it thorns the travelers' attacks (heroes only).

Tests: `EffectFixesV131Tests` (Overload, Retaliation, Finale, pact curse rules, registry, first-zone depth).
