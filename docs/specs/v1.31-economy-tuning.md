# v1.31 遺物の手に入りやすさと合成・分解の見直し

利用者の要望（2026-10-03）：一括分解するクオリティを自分で選べるようにする。エピック以上の入手難易度を上げる。合成に必要な個数を増やす。固有はさらにコストを大きくする。

## 決めたこと

| 項目 | いま | 変更後 |
| --- | --- | --- |
| まとめて分解 | コモン・アンコモン固定 | 「〜まで分解」をコモン／アンコモン／レア／エピックから選ぶ（既定アンコモン、プロフィールに保存）。固有品・鍵つき・装着中・取引中は対象外のまま。レア以上を含むときは確認を2回押しにする |
| エピック以上の出やすさ | — | エピックとレジェンダリーの抽選の重みを下げる。ボスでエピック以上が確定する救済も、確定までの回数を伸ばす（具体的な値は非公開の開発メモにだけ書く） |
| 合成の個数 | どのレア度も3個 | コモン→アンコモン 5個、アンコモン→レア 5個、レア→エピック 6個 |
| 固有品の合成 | エピック3個＋欠片40 | エピック8個＋欠片150＋調律石2 |

ポイントを配ったり、既存の遺物を変えたりはしない。保存形式は変えない（分解の設定を1つ足すだけで、古い保存には既定値を入れる）。
