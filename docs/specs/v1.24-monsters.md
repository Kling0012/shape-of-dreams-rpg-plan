# v1.24「モンスター側のつり合いと、新しい敵」

利用者の助言（2026-10-02）：プレイヤー側の話をしているけど、合わせてモンスター側とどうやって遊ぶうえでバランスを取るかは大事。新しいモンスターを作れたら一番すごい（Blender・BlenderMCP、Lab の3D生成の利用可）。

本体の調査は [v1.24-monster-research.md](v1.24-monster-research.md)。

## いまの穴

プレイヤーは 6枠・固有品334・星図35ポイント・覚醒・強化の節目・新しい固有効果で大きく伸びた。
一方、敵は「悪夢化」（深度に応じた確率）と本体の難度・Limbo だけで、悪夢でない敵は深度で強くならない。深度は主にドロップと被ダメージを増やすだけ。

## 方針

1. **層A：今ある仕組みで、敵を深度とプレイヤーの強さに合わせる**（ホストの `ProcessSpawns` で、`StatBonus` を足すだけ。通信は既存のまま）
   - 悪夢でない敵にも深度に応じた上乗せ：深度1ごとに最大HP +8%・攻撃力 +4%（深度3から防御 +10）。ボスは深度4から最大HP +10%/深度。
   - 悪夢化の確率に「装備の強さ」の係数（装着している遺物のレア度・強化・覚醒から。上限あり）。強い装備で潜るほど、手応えのある敵が増える。
   - 悪夢の性質を4つ追加（`NightmareAffix` の空きビット）：結界（出現時に最大HPの25%の障壁）、棘皮（受けたダメージの一部を反射）、飢渇（与ダメージで回復）、破甲（当たると防御を一時的に下げる）。
   - 報酬：強くなった分、悪夢と変種の報酬の格を上げる（落ちる量ではなくレア度）。
2. **層B：本体の敵をもとにした「夢の変種」6種**（深度2以降、部屋に最大1体。名札・色・大きさで見分けられる）
   - 本体のプレハブ＋`StatBonus`＋本体のエリート効果（MirageSkin・MiniBoss・HunterBuff）＋ MOD のイベント処理＋色と大きさ。
   - 新しい通信 `DreamforgeVariantMsg(netId, variantId)` で、全員の画面に名札・色・大きさを付ける。
   - 候補：蝕む猟犬、鏡面のスカラベ群、虚ろな砲手、焔の殉教者、平衡の番人、欠片喰らい（それぞれ、特定の戦い方への挑戦と報酬を持つ）。
3. **層C：新しいモデルの技術検証**（次の版以降）
   - 本体の敵1体の見た目を、Blender で作った静的なモデルに差し替える試し（AssetBundle と `EntityVisual.LoadModelLocal`）。Unity の版・シェーダー・OS ごとのバンドルが課題。Lab（RTX 3090）の3D生成（Hunyuan3D など）を下絵に使えるか試す。

## 確かめること（実機）

- `Dew.SpawnEntity` の持ち主・レベル、`SpawnMonsters` で部屋のクリア判定が壊れないか。
- 色・大きさの変更が全員に同期されるか（されなければ MOD の通信で各自が付ける）。
- 深度ごとの敵の上乗せで、遠征が理不尽にならないか（BalanceSim では敵の強さは測れないので、実機で戦闘時間を見る）。
