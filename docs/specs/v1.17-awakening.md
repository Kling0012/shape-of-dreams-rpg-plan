# v1.17「遺物の覚醒」

利用者の目標（2026-10-02）：コンテンツと遊戯性をいっぱい増やす。

## ねらい

固有品（伝説）は、手に入れた時がいちばん嬉しく、そのあとは装着して終わりになりがち。
**使い込んだ固有品が目覚めて強くなる**仕組みで、「この1本を育てる」愛着と、次の遠征へ出る理由を作る。
強い装備に乗り換えるか、覚醒の近い愛用品を使い続けるかという、小さな迷いも生まれる。

## 土台にする本体の仕組み

- 本体の敵の種類（`Monster.type`：通常・エリート・ボス）と、このMODの悪夢化。倒した敵の重さで進み具合が変わる。
- 撃破は `ClientSession` が本体のキルイベントから `Rules.OnKill(…, heroKey, …)` を呼ぶ流れをそのまま使う（倒したのが自分の旅人のときだけ）。

## ルール

- 対象：レア度が伝説（固有品・セット品）の遺物。
- 装着している旅人が敵を倒すと、装着中の固有品それぞれに「覚醒の力」がたまる。
  - 通常の敵・弱い敵：1、エリート：5、ボス：20。悪夢化した敵は2倍。
  - 1つの遺物につき 500 で覚醒（目安：遠征2回ほど）。
- 覚醒すると、その遺物の固有効果が1.5倍、特性（接辞）が1.2倍になる（切り捨て。合計の上限はこれまでどおり）。
- 覚醒は一度きり。分解・合成すると失われる（表示で警告する）。
- 覚醒の瞬間に知らせを出す（「『○○』が覚醒しました！固有効果が1.5倍になります」）。
- 偉業を2つ追加：「目覚めの刻」（1つ覚醒させる）、「覚醒の主」（5つ覚醒させる）。
- 記録：覚醒させた数を数える。

## 画面と文章（Claude）

- 遺物の詳細：「覚醒まで 123/500（倒した敵で溜まります。エリート5・ボス20・悪夢化は2倍）」。覚醒済みは「✦ 覚醒済み：固有効果1.5倍・特性1.2倍」。
- 遺物の名前の前に、覚醒済みなら「✦」。
- 鍛冶で覚醒済みの遺物を分解しようとしたら、確認の文に「覚醒が失われます」を入れる。
- 遊び方と、偉業の文章。

## ルール側（GPT）

- `Relic` に `AwakenPoints`（int）と `Awakened`（bool）。保存・読み込み（`ProfileCodec`）。古い保存は 0 / false。
- `Content.AwakenThreshold = 500`、`Content.AwakenPowerPct = 150`、`Content.AwakenAffixPct = 120`、`Content.AwakenPoints(MonsterTier, bool nightmare)`。
- `Relic.EffectivePowers()` と `EffectiveStats()` の接辞部分に覚醒の倍率を掛ける（基礎能力には掛けない）。
- `Rules.OnKill`：heroKey があれば、その旅人が装着している伝説の遺物に力を足し、閾値で覚醒させて知らせを返す。`Stats.RelicsAwakened` を増やす。
- 偉業2つ、試験。
