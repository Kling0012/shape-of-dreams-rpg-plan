設計対象は `Hero_Aurena`。新しい星は原則1段。**購入できる星743個、始まりの星を含む表示頂点744個**を設計する。内訳は既存73個のIDを維持した再設計、新しい記憶星団392個、橋の増設112個、新刻印6個、共有外縁160個。本書固有部分の全体能力値だけの星は0個。実装済みという意味ではなく、下記の連動機構と検証条件を満たす実装への入力表である。

## 表の読み方と共通実行契約

| 記法 | 星の種類・厳密な意味 |
|---|---|
| `D(m,x)` | `MemoryDamage(m,+x%)`。その記憶由来の本体ダメージだけ。回復・犠牲HP・生成ダメージは増やさない |
| `B(m,x)` | `GimmickBoost(m,+x%)`。その記憶の仕掛けの数値Valueへ加算倍率。下記受信定義では `ReceiverMemory=m` の受信量も含む。装備のPowerや本体記憶の値は対象外 |
| `U(m,x)` | `GimmickParam(m,Duration,+x%)`。既存のShield/Expose、取得済みWound/Sap/Rampart/AlliedWardの持続だけ。腐食・羽根・魔法陣・属性寿命・CD・Echoの遅延は変えない |
| `R(m,x)` | `GimmickParam(m,Radius,+x%)`。取得済みBurst/OnKill Elementの範囲、Ricochetの検索半径、AlliedWardの味方検索半径だけ。単体Elementや本体の射程は対象外 |
| `X(m,1)` | C03 EffectChannel scopeの`GimmickParam(ExtraTargets,+1)`。取得済みRicochetの別敵を基礎1→最大2体へ増やす。memory-wideにしてRampartの対象数まで増やさない。現行にはこの限定scopeがない |
| `G(m,t,e,v,a,c)` | `Notable`。`Memory=m; Trigger=t; Effect=e; Value=v; Arg=a; Cooldown=c` の完全なGimmickDef。秒数以外の数値は原則%係数。`OnHit/OnCrit/OnKill/OnUse`は省略しない |
| `Recv(s,t,v)` | 受信指定付きNotable。`Memory=s; Trigger=t; Effect=Recharge; Value=v; Arg=0; Cooldown=0; ReceiverMemory=M`。発動はs、短縮対象だけM。現行GimmickDef単独には受信欄がないため新機構AU1が必要 |
| `Ward(m,t,v)` | `G(m,t,AlliedWard,v,0,0)`。新効果AU3。既存Shieldの別名ではない |
| `one` | AU2の発動単位ゲート。同じ星・同じactivationIdにつき1回。実際に発動したときにだけ記録し、次のキャストは即時発動可。時間の内部CDを追加しない |

全増幅は内部で小数を保持する。Value1にB+2%なら1.02%として作用し、途中で整数へ切り捨てない。表の `B` は数値だけを伸ばし、スタック上限・対象数・持続は変えない。ブースト合計は記憶ごとに加算し、最後に効果固有の上限を適用する。Bの合計上限は+160%、Durationは+100%、Radiusは+80%。刻印の別倍率は別計算とし、効果ごとの最終上限を守る。全割当でも小星の増分が上限に吸収され尽くさない数値を検証する。ExtraTargetsは2体の上限を超える同種星を作らない。

| 効果 | 採用する既存の意味・重複上限 |
|---|---|
| Element | Value100ごとに1スタック、余りは追加1スタックの確率。Arg0火/1冷気/2光/3闇。火は本体に個数上限なし、冷気1・光5・闇5。すべて非消費。Valueの共通上限600と属性本体上限を区別する |
| Burst / Echo | Burstは高い方のAD/APのValue%、基準4m。Echoは実命中量のValue%を0.3秒後。ともにValue上限1000%。無属性・攻撃効果なし・再増幅/再発動なし |
| Expose | 対象に対する自分の与ダメージ増幅、基準4秒。同時に最大値1つ。上限100%。味方全員への弱体ではない。Eclipseとも高い方のみ |
| Wound | 高い方のAD/APのValue%を基準3秒で与える。対象ごと最大1つ、上限120%。通常Durationは基準tick威力を維持し末尾を延ばして総量も増える。0.5秒tickと端数時間比例、再適用でtick位相を遅らせない。刻印の明示総量/時間交換だけは通常Duration適用後の総量を指定倍率にして時間へ再配分する |
| Sap | 敵の与ダメージ低下、基準4秒、ボス/ミニボスは半分。最大値1つ、上限15%。OnHitだけ |
| Rampart | 同じ発動で異なる敵5体まで、1体につき最大HPのValue%、基準4秒。Value上限2%、合計10%。同時に大きい方1つ。OnHitだけ |
| Daze | Value4なら0.4秒スタン。上限0.8秒、同じ敵へ5秒に1回。ボス/ミニボス無効。星のCooldown0でもこの既存対象別制限を守る |
| Ricochet | 実命中ダメージのValue%を8m内の別敵Arg体まで。Value上限50%、Arg1–2。CD0.3秒は現行実装の必須下限で、多段/貫通から反射が過密発生するのを抑えるため維持 |
| ElementEdge | 敵にある属性1種類につき高い方のAD/APのValue%。最大4種類、Value上限40%、合計160%。スタックを消費しない |
| Recharge | 指定記憶の現在残りCDのValue%を短縮。Value上限100%。短縮不可設定・残り0・最大2チャージを尊重し、チャージ数を直接増やさない |
| Shield | 既存幹だけに残す。最大HPのValue%、基準4秒。無限加算を避けるためAU4の有限プールに移す。回復に変換しない |

回復/障壁を発生させる場合は `ActorManager.serverActor` を用い、旅人の本体支援通知を回さない。すべての生成ダメージは `GimmickRuntime` マーカーを付け、仕掛け・合わせ技・属性反応・本体の攻撃効果を起動しない。装備解除/ゾーン遷移/死亡で一時状態を破棄する。通常の再送だけではゲートをリセットしない。

## A. 記憶領域：7記憶×4星団×14星

全星団の固定IDは `aurena.mem.<slug>.c1`〜`.c4`。各行は入口6星、中心2星、選択1星、中心後の枝葉5星の**14個**に展開する。選択の未選択肢を星として数えない。

| 型 | `.e1`〜`.e6`（順に6個） | `.l1`〜`.l5`（順に5個） | 接続・意味 |
|---|---|---|---|
| S（持続） | `D(m,2); B(m,2); U(m,2); B(m,2); U(m,2); B(m,2)` | `B(m,2); U(m,2); B(m,2); U(m,2); B(m,2)` | 既存幹7→e1→e2→e3→n1、e2→e4→e5→e6→n2。n1→l1→l2、n2→l3→l4→l5、l2/l5→選択。Uは幹のShield/Expose/Sapに初めから作用 |
