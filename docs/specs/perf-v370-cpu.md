## A01 HUDのBuild再計算

見送った。`ClientSession.CurrentBuild` と `DisplayBuild` は変更していない。表示用の0.25秒の期限を残した。

`MarkDirty(true)` は既知の変更でキャッシュを無効にするが、Build入力全体を表すrevisionではない。`HeroState.Equipped` と `Keystones` は配列、`Talents` と `TalentChoices` は変更可能な辞書、`RunState.Pacts` は変更可能なListで、HeatやDailyIdにも共通の変更通知がない。遺物の強化・覚醒・融合・特性・固有効果も公開setterやListから変更できる。Buildは熟練度のKillsや、星の定義レジストリも参照する。`Profile.Revision` は保存時に増える値で、これらの変更すべてを即時に表す値ではない。

古いホスト向けのcapability確認、互換Profile、送信用Buildの計算も変更していない。A01のrevision方式による再計算抑制は未実装。
