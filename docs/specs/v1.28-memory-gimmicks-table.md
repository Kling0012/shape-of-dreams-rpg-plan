# v1.28 記憶の仕掛け 設計表（62ルート × mid2・mid・cap）

仕組みと列の意味は [v1.28-memory-gimmicks.md](v1.28-memory-gimmicks.md)、記憶の動きは [v1.27-traveler-kits.md](v1.27-traveler-kits.md) を正とする。この表はデータ投入用の設計で、コードは含まない。

## 方針

- 目的は能力値を高くすることではなく、**遊び方を横に広げること**。倒すと再使用が近づく、属性を付けて別の記憶や四元の共鳴につなぐ、Expose で味方や別の記憶の起点を作る、Echo で手数を変える、味方を癒やし守る、を中心にした。
- Empower と Quicken（一時的な能力値上昇）は全体の2割以下に抑えた（件数はまとめを参照）。
- どの仕掛けも、その旅人の今の戦い方（アイデンティティ・旅人記憶・固有星座）に合うか確認し、**列「邪魔にならない理由」**に1文で書いた。本体の仕組み（Vesper の4回目の会心、Cetus の氷の血脈・帯電のスタック、Yubar のエキゾチック物質の蓄積など）は上書きせず、命中・会心・撃破に「反応して足す」だけにしている。操作を奪う効果（勝手な移動・向きの変更）はない。敵の引き寄せも、遠距離のラセルタ・ユバールの邪魔になるので採らなかった。
- 旅人別の注意：
  - アイデンティティは遠征の前に選べるもの（[v1.27-traveler-kits.md](v1.27-traveler-kits.md) 末尾の表。Bismuth は1つ、ほかは2つ）だけを考える。アイデンティティのルートの仕掛けは、そのアイデンティティを着けている時だけ効くので、その性質に合わせてよい。
  - 旅人記憶（Q・R・移動）のルートの仕掛けは、その旅人の2つのアイデンティティのどちらと組んでも成り立つようにし、列「邪魔にならない理由」にその理由を書いた。特定のアイデンティティでしか生きない条件（通常攻撃での発動、攻撃速度の上昇）は避けた。
  - Q・R も遠征の前に候補から1つずつ選ぶので、同じ枠の候補どうし（例：ハンドキャノンと焼夷弾装填）は同時に装備されない。他の記憶と組み合わせる仕掛け（RechargeOther など）は「装備中の他の記憶」にだけ働き、特定の記憶の存在を前提にしない。
  - Bismuth はアイデンティティが固定（プリズムの視界）なので、基本攻撃は本が自動で行う前提でよい。OnUse と「基本攻撃で発動」は置かず、記憶やアイデンティティのダメージへの OnHit／OnKill のみ。
  - Husk のアイデンティティは一歩一殺（攻撃速度を攻撃力に変換）と風の傷（攻撃速度が普通に効く）の2つなので、旅人記憶のルートに Quicken は置かない。
  - Aurena は HP を捧げる・低HPで強い構成なので、現在HPを上げる効果は少なめにし、HPに触れない Shield を優先した。
  - Lacerta・Yubar は距離を取る旅人。引き寄せ・近接前提の効果は置かない。
- 移動の記憶（`St_M_`）は OnUse を置かない。ダメージを出す重装タックル・フロストチャージだけ OnHit を置く。ダメージのない移動の記憶（速攻回避・変光星・瞬歩・クイックフット・夢幻のワルツ・フェザーダッシュ・歪な疾走）とダメージのない生命の循環は **none**。none の星は仕掛けを置かず、常時の効果（回避のチャージ数・クールダウン・移動速度など）のまま残す。

## 読み方

- 位置：`mid2` は2番目の星（小さな仕掛け。段数はデータ側に従い、Value は1段あたり。mid の半分以下の強さ）、`mid` は4番目の星（3段、Value は1段あたり）、`cap` は頂点（1段、ルートの看板）。
- Arg：Element は 0 火 / 1 冷気 / 2 光 / 3 闇。Heal は 1 で近くの味方も回復。それ以外は 0。OnKill の Element は、倒した敵の近く（4m）の敵に付ける解釈とする。Cooldown は秒。
- 星2の目安（1段）：Element 30 / Expose 3 / Shield 1〜2 / Heal 1 / Echo 6〜8 / Recharge 4〜10。
- 末尾に ★ のある Effect は「新しい効果の提案」（表の最後に説明）。
- 実装メモ：`St_R_BackOff` の Quicken は障壁が出ている間の加速（Quicken は4秒）。クールダウンを持たない記憶（アイデンティティ）に Recharge は置かない（代わりに RechargeOther を使う）。

## 新しい効果の提案（★）

9種類にない動きのうち、旅人の戦い方を邪魔しないものだけに絞った。どちらも「命中・撃破に反応して足す」だけで、移動や向きを奪わない。（Spread と Brand は見送り、既存の効果に置き換えた。）

## 仕様の注記

- 仕掛けで出るダメージ（Burst・Echo）は属性なしとし、本体のスタック（氷の血脈・チャージされたアンギリアンなど）や、ほかの仕掛けを増やさない。
- 仕掛けの回復・障壁が、本体の付与条件（群れの心臓の団結など）を起こさない扱いにできるかは、実装で確かめる。起こしてしまう場合は、ナキアの仕掛けの Heal・Shield を団結の引き金から外す。
- OnKill の Element は、倒した敵の近く（4m）の敵に付ける扱いにできるか、実装で確かめる。
- 「要確認（判定次第）」の行（ナキアの召喚獣・味方の攻撃）は、記憶のダメージとして判定できない場合、同じ行に書いた代わりの形に切り替える。
