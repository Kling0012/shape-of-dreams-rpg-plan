# v1.28 記憶の仕掛け 設計表（63ルート × mid・cap）

仕組みと列の意味は [v1.28-memory-gimmicks.md](v1.28-memory-gimmicks.md)、記憶の動きは [v1.27-traveler-kits.md](v1.27-traveler-kits.md) を正とする。この表はデータ投入用の設計で、コードは含まない。

## 読み方と方針

- 位置：`mid` は4番目の星（3段。**Value は1段あたり**で、3段振ると3倍）、`cap` は頂点（1段、ルートの看板）。
- Arg：Element は 0 火 / 1 冷気 / 2 光 / 3 闇。Heal は 1 で近くの味方も回復。それ以外は 0。Cooldown は秒。
- 強さは仕様の目安内。mid は「3段で目安の上限付近」、cap は「1段で目安の中〜上限」。Burst/Echo は仕掛けから出たダメージでは連鎖しない。
- アイデンティティ記憶は発動しないので OnUse は置かず、OnHit／OnCrit／OnKill（その記憶のダメージ）だけを使う。
- 移動の記憶（`St_M_`）は OnUse を置かない。ダメージを出す重装タックル・フロストチャージだけ OnHit を置く。ダメージのない移動の記憶（速攻回避・変光星・瞬歩・クイックフット・夢幻のワルツ・フェザーダッシュ・歪な疾走）と、ダメージのない生命の循環は **none**。none の星は仕掛けを置かず、常時の効果（回避のチャージ数・クールダウン・移動速度など）のまま残すことを提案する。
- 実装メモ：`St_R_BackOff` の OnUse Quicken は障壁が出ている間の加速（Quicken は4秒）。`St_D_ExoticMatter` はクールダウンを持たないので、cap の Recharge は「装備中の他の記憶の残りクールダウンを縮める」と解釈する案（ホストで要判断）。一歩一殺は攻撃速度の恩恵を受けないため、Quicken は置いていない。
