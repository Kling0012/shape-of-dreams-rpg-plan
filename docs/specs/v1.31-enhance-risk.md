# v1.31 強化の伸びを下げ、失敗を付け、上限で空振りしないようにする

利用者の要望（2026-10-03）：強化の+によって強化で受ける収益を下げる。強化に失敗の可能性を付与し、上限に近付くほど大きくする。失敗したら強化値が+0に戻る（遺物は残る）。あわせて、固有効果の合計上限で強化・覚醒が空振りする件（[監査](../reviews/effect-wiring-audit.md) 3.4）を直す。

## 強化の伸び（合計、+0からの増分）

| 強化値 | 固有効果 | 特性 |
| --- | --- | --- |
| +5 | +20%（いま +25%） | +26%（いま +30%） |
| +10 | +32% | +40% |
| +15 | +40% | +50% |
| +20 | +45%（いま +70%） | +56%（いま +90%） |

段ごとの値は表で持ち、間の段は1段ずつ小さくなる（試験で単調に増え、増え幅は減ることを確かめる）。

## 失敗

- 鍛冶タブの強化だけが対象。出来事（鍛冶の祠・焼き入れの祭壇など）による強化は必ず成功。
- 目標の強化値ごとの失敗の確率：+1〜+3 は 0%、+4 は 5%、+5 は 10%、+6〜+10 は 15〜35%、+11〜+15 は 40〜60%、+16〜+20 は 65〜85%（1段につき +5%）。
- 失敗すると強化値が +0 に戻る。遺物・限界突破の回数・覚醒は残る。払った欠片は戻らない。
- +20 で一度付いた「1つ目の固有効果×1.2」は、+0 に戻っても残し、もう一度 +20 にしても重ねて付けない（同じ遺物には1回だけ）。
- 画面：失敗の確率と「失敗すると+0に戻る」を強化ボタンの近くに出し、確率があるときは2回押しで確定する。結果（成功・失敗）を通知に出す。
- 乱数はプロフィールの乱数（決定的）を使い、保存の直前に確定する（やり直しで結果を変えられないように）。

## 固有効果の合計上限

- 上限（`PowerCap`）は、強化・覚醒・+20 の倍率を掛ける前の「元の値」の合計に掛ける。
- そのあと、各遺物の倍率を、上限内に収めた元の値の割合に応じて掛ける。
- 最終の値は、元の上限の 2.5 倍まで。
- 連携（記憶加速など）の上限も同じ考え方にする。
- ホストの検証（HostBuildValidation／HostGearValidation）も同じ計算で作り直し、往復で一致することを試験で確かめる。
