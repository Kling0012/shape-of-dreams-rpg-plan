# Issue #47: 刻印のデバフ撤廃とバフ説明の整合（照合結果）

日付: 2026-10-05。対象: `fix/issue-47-sigil-debuff`（Issue #47）。

## 方針

- 刻印（Keystone、星図の紫の大星・全82個）から**デバフ（代償/Downside）を実効果・説明・UIから撤廃**した。
  - データ: `tools/star-manifest/*.json` の `downside` / `downsideSpec` を全行から削除し、生成物（`StarClusters/*.Generated.cs`）を再生成。
  - Core: `KeystoneDefinition.Downside`・`KeystoneOperation.Disable` / `RedistributeWound`・`KeystoneScope.Condition`（M6 条件付き代償）・`HasNativeDownside`・`AuthoredKeystoneComposer.RefundStarIds` を削除。ctor の「downside 必須」検証を解除。
  - 表示: 説明は「効果（利点）+ 必要ポイント」だけになった（`StarMapPresentation.KeystoneDescription` / `Content.TalentDef.Describe` / WikiGen）。効果本文は**型付き upside から自動生成**（`DescribeKeySide`）し、手書きprose（`KeystoneUpside/KeystoneDownside`）での上書きを廃止 → 説明と実効果の矛盾が構造的に起きない。
  - UI: 星図凡例から「利点と代償の両方があります」を削除。
- C15（払い戻し承認）は依存星の連鎖払い戻し等で使われ続けるため残す。刻印の代償で星が無効化される経路は消滅（Disable 変換の全生産者が無くなった）。
- C11（h.aurena.key2 満ちた聖杯）: upside の「HP支払い→障壁」はそのまま、同時要求していた native downside（G/D の最終ダメージ-40%）は撤廃。admission はネイティブ自傷アダプターの束縛状態のみで判定する。
- 互換性:
  - **セーブ**: 保存形式 4 のまま。刻印は ID のみ保存（`keystone` / `keystones`）で、デバフ状態は一切保存されないため、残留データは無い。旧セーブはそのまま読める（読込・移行処理は無変更）。
  - **協力プレイ**: ビルドの `k:` レコード（刻印定義の符号化）から downside 変換列と条件が消えたため、`Protocol.Version` を 14 → 15 へ。版が違うホスト/参加者は従来どおり警告が出て一緒に遊べない。
