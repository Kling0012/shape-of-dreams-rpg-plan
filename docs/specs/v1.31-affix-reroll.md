# v1.31 特性の洗い直し

利用者の要望（2026-10-03）：特性を洗い直せる機能も欲しい。コストは大きくてよい。

- 鍛冶タブに「特性を洗い直す」を足す。遺物の特性を**全部まとめて**引き直す（特性の数・レア度・土台・強化値・限界突破・覚醒・固有品の固有効果はそのまま）。
- 引き直しは、その遺物を新しく作るときと同じ抽選（同じレア度・同じ枠の特性の候補・同じ値の範囲）を使う。
- 回数の上限はない。費用は欠片 60×(レア度+1) と調律石 2×(レア度+1)。同じ遺物で使うたびに1.5倍（切り上げ）。回数は遺物に保存する。
- 2回押しで確定する（結果はすぐに決まり、取り消せない）。鍵つき・装着中・取引中・再調律の候補が出ている遺物は対象外。
- 既存の「再調律」（特性1つを3つの候補から選ぶ、回数上限あり）はそのまま残す。
- リリースノートには機能だけを書き、費用は書かない。
