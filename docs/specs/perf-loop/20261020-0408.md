# perf-loop/20261020-0408

## 対象

native Dew.Core/Room.cs。毎フレームの経路は持たないファイルで、プレイ中に走るのは部屋の開始・終了・掃除（1部屋ごと1回）と、SyncVar・RPC の受信である。このうち参加者（ゲスト）側で部屋に入るたびに走る `UserCode_RpcInvokeRoomStart`（`Room.cs:757`）が呼ぶ `GetSortedByStartDependency`（`Room.cs:572`）を直した。ホストも `StartRoom`（`Room.cs:488`）で同じメソッドを部屋ごとに呼ぶ。

## 直した内容

`GetSortedByStartDependency` は、部屋の RoomComponent を起動順に並べ替えるメソッドで、呼ばれるたびに次の無駄をしていた。

1. 部件ごとの `GetType().GetCustomAttributes(...)`。同じ型でも呼ぶたびに属性のインスタンスと配列を作り直すリフレクションで、部屋に入るたびに毎回繰り返していた。
2. 位相ソートの本体の `array[m].Any(...)` と `Where(...).ToArray()`。取り出した部件ごとにクロージャと列挙子を確保する LINQ で、部件数の2乗のオーダーで確保が続く。

Harmony の Prefix で元の処理を置き換えた（`NativePerfPatches.cs` の `NativeRoomStartDependencyPerf`）。属性の配列は型ごとに静的な辞書へキャッシュして部屋をまたいで使い回し、LINQ の代わりに数えながら作り直す素のループにした。元のメソッドが見つからない・形が違うときはパッチを当てずに警告を1回出し、置き換えた処理が例外を出したときも元の処理へ戻す（設定 `nativeRoomStartDependency`、既定は有効）。

## 結果が変わらない理由

置き換えた処理は、元と同じ「依存のない部件から順番にキューへ入れて、依存が外れた部件を続けてキューへ入れる」算法で、入力の配列と同じ型ごとの属性配列に対して同じ順序で動く。出力の並びと、依存が環のときの `Circular dependency detected.` の例外も同じである。属性の中身は型だけで決まり、処理の外へ出ないので、型ごとのキャッシュは毎回のリフレクションと同じ値を返す。属性配列は収める側の `Where().ToArray()` と同じく、一致した分を除いた新しい配列を作って差し替えるだけで、キャッシュした配列を書き換えない。

## 効果の見込み（推定）

部屋に入るたびに、ホストで1回、ゲストでも1回（RPC の受信）、部件ごとのリフレクションと LINQ の確保がなくなる。部屋の RoomComponent は数十個と見込むので、1回あたり数十〜数百個のアロケーションと属性インスタンスの作り直しを省く（推定）。部屋の中では走らないため毎フレームの負荷は変わらず、部屋の切り替え時のスパイクと GC への圧力が下がる。2部屋目以降は属性探しが辞書引きになる。

## 検証

`python3 tools/balance/gen_cs.py --check` は合格。`dotnet build src/SodRpg.Mod -c Release -p:GameDir=... -p:ModDeployDir=/tmp/perfloop-x` は合格（警告6件は既存のもの）。`DOTNET_ROLL_FORWARD=LatestMajor dotnet test tests/Issue73.Native.Tests -c Release` は551件合格。`DOTNET_ROLL_FORWARD=LatestMajor dotnet test tests/SodRpg.Mod.Startup.Tests -c Release` は225件合格・1件スキップ（元から Skip の ModReloadTests）。

並べ替えの等価性は `tests/Issue73.Native.Tests/RoomStartDependencyPerfTests.cs` で確かめる。テスト内に本体の LINQ 版（`GetCustomAttributes` → `Any` / `Where().ToArray()`）と同じ参照実装を置き、依存なし・一方向の連鎖・1つの部件への複数依存・同じ型の部件の重複・継承した属性・環（例外の型とメッセージ）の6つの場面で `SortByStartDependency` との出力の並びを比べる。あわせて、同じ型が2回出る入力を2回呼んでもキャッシュした属性配列が書き換わらないことも確かめる。
