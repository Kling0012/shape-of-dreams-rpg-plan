# perf-loop/20261019-0931

対象: 本体 `Dew.Core/AbilityTrigger.cs`（チャージ数の同期送信。`SkillTrigger` のクールダウン減少経路で送る同一の RPC を含む）。

直した内容: チャージ数の同期は 4 箇所すべてが、最後に `RpcSetCharge(configIndex, currentCharges[configIndex])` を条件なしで全員へ送る。`SetCharge`、`ApplyCooldownReductionWithMinimum_Imp`、`ApplyCooldownReductionByRatio_Imp`、`SkillTrigger` 独自の減少処理の 4 箇所である。クールダウン減少がチャージの補充（ロールオーバー）を起こさなかったとき、この値は変わっておらず、受信側の `UserCode_RpcSetCharge` は同じ int を書き戻すだけで、他の作用は何もないため、その送信は無駄になる。`NativePerfPatches.cs` に `NativeChargeRpcIdlePerf` を足し、`RpcSetCharge` の送信前に、ホストがこのトリガーと設定について最後に送った値と同じなら送信を省くようにした。最後に送った値は `ConditionalWeakTable` でトリガーごとに記録し、チャージ配列のインスタンスが変わったら（Dew はアクターをプールで再利用し、`OnStartServer` が生成のたびに配列を割り直す）記録を空に戻す。設定は `nativeChargeRpcIdle`（既定で有効）。パッチ先が見つからないときは警告を 1 回出して無効になる。

結果が変わらない理由: 参加者は `currentCharges` を自分では変更しない。`LogicUpdate` のチャージ処理はサーバだけで走り、参加者の手元の値は、この RPC、参加・生成時のスポーンペイロード（`OnSerialize`）、生成直後の配列同期 RPC（`RpcSyncAfterFrameDelayStates_Imp`）の 3 つからだけで、いずれもホストの値を Mirror の信頼性のある経路で届く。したがって「最後に送った値」と全参加者が持っている値は常に等しく、同じ値の再送を省いても各参加者で書き込まれる int が同じになるだけで、状態も以降の処理も変わらない。実際に値が変わったときは従来どおり送る。ホストの安全装置（`NativeCooldownSafety` の `Normalize` と `ResendAuthoritative`）のうち、修復の本体は残り時間の RPC（`RpcSetCooldownTime`）のほうで、このパッチは触っていない。同じチャージ値の意図的な再送は省かれるが、受信側の状態が同じため等価である。プール再利用でトリガーが新しい命になったときは、配列の同一性の変化で記録が空になり、前の命の記録で送るべき値を誤って省くことはない。

効果の見込み（推定）: クールダウン減少のイベント 1 回につき、チャージが補充されなかった設定の分だけ RPC 1 通（数バイト + RPC ヘッダー）を全員への送信から省く。クールダウン減少を頻繁に使う構成では、戦闘中に毎秒数通程度の送信と、受信側（参加者全員）の RPC 処理が減る見込み（推定。実機での計測はしていない）。

見た範囲と見送った候補: `Dew.Core/AbilityTrigger.cs` 全体（2258 行）と、そこから毎フレーム（`LogicUpdate`）・被弾やキャストごと・通信ごとに呼ばれる処理を見た。前回までに `NativeCooldownIdlePerf`（待機中の乗数計算の省略）が入っている部分は除いて確認した。見送った候補は次のとおり。（1）`RpcSetCooldownTime`・`RpcSetMinimumDelay` の同じ値の再送を省く案。参加者は残り時間と最短間隔を毎フレーム自分で減らすため、ホストと参加者の値にはわずかなずれが常にあり、本体はキャストのたびに同じ値を送ってずれを即時に直している。省くと参加者の表示が直るタイミングが数フレーム遅れる可能性があり、タイミングを変えないという条件に触れるため見送った。（2）`fillAmount` SyncVar の毎フレーム更新（設定変更の残り時間や状態効果の表示）の間引き。進行バーの表示そのもので、間引くと見た目が変わる。（3）`OnCastComplete` がキャストごとに確保するクロージャ（`configIndex` と `CastInfo` を捕まえるため使い回せない）の削減。Transpiler で本体の仮想メソッドを書き換える規模になるため見送った。
