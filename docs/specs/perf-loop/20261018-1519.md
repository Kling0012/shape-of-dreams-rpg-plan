# perf-loop/20261018-1519

対象は mod src/SodRpg.Mod/ClientSession.BossVisuals.cs（ボス予告の受信と IMGUI 描画）。改善あり。

直した箇所: DrawBossEffects（Repaint ごと）の描画ループと DrawBossWorldLine。カメラ位置（camera.transform.position）、Screen.width / Screen.height、Texture2D.whiteTexture を線分・文字・可視判定のたびに読み出していたのを、Repaint の先頭で一度フィールドへ読んで使い回すことにした。BossDisplayVisible は camera 引数をやめて、そのフィールドのカメラ位置を見る。

結果が変わらない理由: 上げた4つの値は同一の Repaint イベントの中では一定である。OnGUI の処理は同期的に走り、途中でゲーム側のスクリプトや解像度変更は挟まらないため、読み出す位置をイベントの先頭へ動かしても値は同じである。読み出し回数を減らすだけで、判定と描画の内容は変わらない。

効果の見込み（推定）: 線分1本あたり Screen.width 1回・Screen.height 2回・whiteTexture 1回、可視判定1回あたり transform と position の各1回が、ネイティブ側への問い合わせを伴うプロパティ読み出しとして消える。描画線分は上限で 2048 本（低品質 768 本）のため、線分の多い場面ではフレームあたり数千回の読み出しが減る。1回あたり数十ナノ秒の桁と見積もるため、削減はフレームあたり数十マイクロ秒以下と見込む（推定）。

検証: python3 tools/balance/gen_cs.py --check、mod の Release ビルド、Issue73.Native.Tests 278件、SodRpg.Mod.Startup.Tests 149件（1件は環境による既存のスキップ）を通った。ゲーム内での表示は未実行（この環境ではゲームを動かせないため）。
