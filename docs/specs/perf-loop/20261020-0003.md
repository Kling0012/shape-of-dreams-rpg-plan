# perf-loop/20261020-0003

## 対象

mod src/SodRpg.Mod/ClientSession.BossVisuals.cs（MOD 側のボス予告表示。ホストから届く DreamforgeBossEffectsMsg／BossLiteMsg の受信と、OnGUI の Repaint ごとのワールド線分描画。ゲストも毎フレーム・通信ごとに通る経路）。

## 直した内容

ボス予告の線分描画（リング・ファン・ストリップ・放射スポーク）は、線分1本ごとに両端点を `Camera.WorldToScreenPoint` で投影し直していた。隣接する線分は端点を共有するため、同じ頂点を同じ Repaint の中で最大2回投影することになる（リング s セグメントで 2s 回の投影に対し、実際の頂点は s+1 個）。

画面座標を受け取って1線分を描く本体 `DrawBossWorldSegment` を抽出し、頂点を共有する図形は各頂点を1回だけ投影して使い回すようにした。ストリップは4隅を投影して4線分（8回→4回）、ファンは中心を1回にまとめて弧をたどる（2(s+2) 回→s+2 回）、リングは隣接セグメントで端点を渡す（2s 回→s+1 回）、放射スポークは中心の投影をループ外へ出し、矢頭の2線分でも頭の点を共有する（スポーク1本あたり 2回→1回＋矢頭 4回→3回）。スポークの中心投影は「1本以上描くとき」だけ行うガードの後ろに置き、予算切れ・本数0のときは旧経路と同じく投影しない。1本だけの単純な線（ビーム・茎・十字など）は従来どおり `DrawBossWorldLine` を使い、予算が尽きたときに投影自体をしない挙動も含めて従来同様にした。

あわせて、線分ごとに `GUI.matrix` を読み戻して保存・復元していたのを、`DrawBossEffects` が描画前に設定した identity 基底へ直接戻す形に変え、線分ごとの native プロパティ読み取りを1回削った。

修正ラウンド（レビュー #890 F1）では、`DrawBossWorldSegment` のカリングと矩形・回転の計算を `src/SodRpg.Mod/BossSegmentPlacement.cs` の純関数 `TryPlace`（Vector3・Vector2・Rect・Mathf の構造体演算のみで、カメラ・GUI・エンジン状態に依存しない）へ切り出した。`DrawBossWorldSegment` はこれを呼ぶだけになり、式は同一のままテストプロジェクトから直接呼べる。

## 結果が変わらない理由

同じカメラ・同じ Repaint の中で `WorldToScreenPoint(同じワールド点)` は同じ値を返すため、共有頂点の使い回しは各線分の画面座標を一切変えない。線分の始点・終点の向きも従来どおりで、矩形の張り方・回転・カリング判定は同一の式のまま `BossSegmentPlacement.TryPlace` へ移した。セグメント予算（`_bossSegmentsLeft`）は線分1本あたり1の消費のままで、描かれる順序も同じ。各ヘルパーには冒頭の予算確保（リング segments、ファン segments+2、ストリップ 4、スポークは1本ごとに矢頭込みで 3 または 1）が残っており、スポークの中心投影もガードの後ろのため、途中で予算が尽きて無駄に投影する場面は生じない。`DrawBossWorldSegment` は `DrawBossEffects` とそのヘルパーの中からしか呼ばれず、画面サイズ・白テクスチャ・identity 基底は `DrawBossEffects` が Repaint ごとに設定する値であることを、ファイル冒頭の不変条件コメントに追記して明示した。

`GUI.matrix` は `DrawBossEffects` がループの前に identity を設定し、以後は各線分が自分の回転を上乗せして描いた後に元へ戻す以外に書き手がないため、読み戻し値は常に identity だった。戻し先を定数にしても結果は同じ。

## 効果の見込み（推定）

ゲスト（とホスト）の Repaint ごとの `WorldToScreenPoint`（native 呼び出し）が、多セグメント図形で約半分に減る。高品質時のリング24セグメントで48回→25回、ファン16セグメントで36回→18回、ストリップで8回→4回。`GUI.matrix` の読み取りは描けた線分1本につき1回ずつ減る。予算上限（2048）に張り付く画面を除き、Repaint あたり概ね数十〜数百回の native 呼び出しを削る見込み（推定。実測は未実施）。見た目・判定・数値・通信の内容とタイミングは変わらない。
