# perf-loop/20261018-2250

対象は MOD `src/SodRpg.Mod/CodexView.cs`。図鑑（記録タブから開く一覧）の描画で、`Draw` が IMGUI の再描画ごとに呼ばれる。

## 直した内容

3段目の絞り込みチップ（枠・系統）を描く `DrawChip` は、押されたときの処理を `Action` のラムダで受け取っていた。枠6個と系統3個のラムダはループ変数を捕まえるため、表示クラスとデリゲートが描画ごとに1個ずつ確保される。全体なしに戻す2つのラムダもデリゲートが毎回確保される。図鑑を開いている間は再描画のたびに合計約20件のヒープ確保になる。`DrawChip` を押されて切り替えられるときだけ true を返す形に変え、フィルタへの代入は呼び出し側で直接行うようにした。使わなくなった `using System;` も外した。

## 結果が変わらない理由

`DrawChip` は同じ位置・同じ文字列・同じ GUIStyle でボタンを描き、今選ばれているチップを押しても何もしない。押されたあとの処理（フィルタへ同じ値を代入し、スクロールを先頭へ戻し、一覧を作り直す）をラムダ経由から直接呼び出しに変えただけで、描画も操作も同じ流れになる。

## 効果の見込み（推定）

図鑑を開いている間の再描画1回あたり約20件のクロージャとデリゲートの確保がなくなる（推定。IMGUI のイベント回数に比例する）。削減量は実測していない。

検証は `gen_cs.py --check`、実 DLL を参照した Release ビルド、両テストプロジェクトのビルド（`Issue73.Native.Tests`・`SodRpg.Mod.Startup.Tests`、いずれもエラー0件）を通した。テストの実行はこのセッションでは行っていない。
