# perf-loop/20261019-1110

対象: native Dew.Core/SkillTrigger.cs。

直した内容: `SkillTrigger.ChargeUltimate` は、ウルティメットスキルを持つ英雄がダメージを与える・攻撃がヒットする・敵を撃破する・ダメージを受けるたびにホスト側で呼ばれ、メソッドの末尾で `RpcSetCooldownTime(0, …)` と `RpcSetCharge(0, …)` の2つの ClientRpc を無条件に全員へ送る。一方、状態の変化はすべて `while (num2 > 0f && currentCharges[num] < configs[num].maxCharges)` のループの中で起きる。ウルトがすでに満チャージのとき（実戦のほとんどの時間がこれに当たる）はループが1回も回らず、クールダウン計算・チャージ獲得・`InvokeCurrentConfigCharged` のいずれも起きないまま、全クライアントがすでに持っている値を再送だけしている。攻撃速度の高い英雄では毎秒数十件のダメージイベントがそれぞれ2つのRPC（クライアント数ぶんの送信）になる。そこで Prefix パッチ `NativeUltChargeRpcIdlePerf`（src/SodRpg.Mod/NativePerfPatches.cs）を追加し、`currentCharges[0] >= configs[0].maxCharges` のときだけ元のメソッドを丸ごと省くようにした。チャージが満タンでない間は前置条件に当てはまらず、元の処理が1行も変わらず走る。MOD 設定 `nativeUltChargeRpcIdle`（既定は有効）で切れる。

結果が変わらない理由: 本体コードのどこを調べても、サーバー側が `currentUnscaledCooldownTimes` と `currentCharges` に書き込む経路は、書いた値をその場で送るペア（`SetCooldownTime`・`SetCharge`・`ApplyCooldownReductionWithMinimum_Imp`・`ApplyCooldownReductionByRatio_Imp`・`LogicUpdate` のチャージ補充と超過クランプ・キャスト時の `OnCastCompleteSetCooldownTime`/`OnCastCompleteSetCharge`・`ChargeUltimate` 自身）になっている。送らずに書くのは観測者が存在する前だけ（`OnStartServer` の初期化と、参加者への初回スポーンのペイロード `OnSerialize` に入る値）で、後から入った参加者も初期状態を受け取る。受信側の `UserCode_RpcSetCooldownTime`/`UserCode_RpcSetCharge` は受け取った値を代入するだけで、ホストでは何もしない。Mirror の信頼性のある順序付きチャネルで欠けが起きないため、満チャージ時に再送していた値は全員がすでに持っている値そのものであり、送らないことですり替わる状態はない。ウルトのクールダウンは `SkillTrigger.ShouldTickCooldown` が false を返すためどちらの側でもローカル減算せず、権威側がイベントごとに送る値だけが唯一の情報源で、その送信経路には触れていない。`UpdateSkillBonus` で `configs[0].maxCharges` が現在のチャージ数を下回った場面も `charges[0] >= maxCharges` になるが、超過分のクランプと送信は `LogicUpdate` 側で従来どおり走る。`NativeCooldownSafety` は `ChargeUltimate` を経ずに `RpcSetCooldownTime`/`RpcSetCharge` を直接呼ぶため影響しない。チャージが満タンでないときの前置条件外れで元の処理がそのまま走るので、被弾・撃破・チャージ境界のタイミングと表示は変わらない。

効果の見込み（推定）: 満チャージのウルトごとに、被弾・攻撃ヒット・撃破・被ダメージのイベントごとの2つの全員宛てRPCがなくなる。1件あたりのペイロードは約9バイトだが、Mirror のRPCヘッダ（netId・コンポーネント番号・関数ハッシュ）と送信キューへの積み込み、受信側のディスパッチがイベントのたびに省ける。攻撃速度の高い英雄1人・参加者3人の約1分の戦闘で、ダメージイベントを毎秒20件とすると約2400通のRPCの削減になる（推定）。ホスト側の `NetworkWriterPool` の取得・返却と直列化の仕事も同じ回数減る。ウルトがチャージ中の間の通信は1件も変わらない。
