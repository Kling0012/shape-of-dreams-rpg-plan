# perf-loop/20261019-0632

対象: native Dew.Core/EntityStatus.cs（と、そこから被弾・効果の付与解除・能力変化のごとに呼ばれる経路）。

直した内容: 本体の `EntityStatus.CalculateStats` は、ホストで能力の再計算が終わるごとに、中身が空の ClientRpc `RpcInvokeStatsCalculated`（ペイロード0。writer を一つ取って SendRPCInternal で全クライアントへ送り、writer を返すだけ）を必ず送っている。再計算は効果の付与・解除、StatBonus の変化、レベルや baseStats の変化のたびに起こり、戦闘中は毎秒数百回に達する。この RPC をクライアントが受けて動くのは `ClientEvent_OnStatsCalculated` の発火だけで、本体全体でこのイベントを購読しているのは `Se_GenericStealth`（ステルス効果。`if (isServer)` の中で購読）のアイコン更新のみで、MOD は使っていない。そこで、再計算の開始時と通知の時点の2回で EntityStatus の `syncVarDirtyBits` を読み、どちらにも1つもビットが立っていなかったら（未送信の変更がなく、かつこの再計算で SyncVar が一つも変わらなかったら）この空の通知の送信を省くパッチを追加した（`NativeStatsCalcRpcPerf` と `NativeStatsCalcRpcBaseline`。NativePerfPatches.cs）。設定は `nativeStatsCalcRpcIdle`（既定ON）。初版は入口と出口のビットの等値比較で省いていたが、レビューで「既に立っているビットは同じ SyncVar がもう一度変わっても同じまま（weaver の setter はビットをもう1回 OR するだけ）で、値の変化が比較から見えない」という指摘を受け、両方が0のときだけ省く条件に改めた。

結果が変わらない理由: 省くのは「クライアントから見える状態が何も変わっていない再計算」の通知だけである。再計算が書きうるクライアントから見える値（bonusStats、finalStats、currentHealth/currentMana の書き直し、basicEffectMask、各 total、シールド、ステルスの2フラグ、overridenAttack）はすべて EntityStatus の SyncVar で、Mirror 自身の dirty ビットが「何が変わったか」の要約になる。値の変化は weaver 生成の setter が必ず自分のビットを立て、ビットは通信の送信時にしか消えず再計算の同期的な呼び出しの内側では消えない。そのため、開始時に1つもビットが立っていなければ、この再計算中の値の変化は必ず通知時点のビットに現れ、両方の読み取りが0なら何も変わっていない（ホスト側で唯一の購読者が読む `isUndetectableByNonAllies` も変わっておらず、アイコン更新は同じ値の書き直しになるため、実行しなくても結果は同じ）。開始時に1つでもビットが立っていたら（前回の再計算の変更がまだ未送信の同期窓の中）、たとえこの再計算が何も変わらせていなくても従来どおり通知を送る。既に立っているビットは上記のとおり値の二重変化を隠すため、ビットの比較だけでは「変わっていない」を証明できないからである。この窓で送る余分な通知は購読者の冪等な処理をもう1回走らせるだけで、同期間隔（既定0.1秒）1回分のあいだだけ続く。リモートの参加者には、本体のコード上このイベントの購読者が最初からいないため、届いた RPC は何もしない。通知を送る側の本体コードが Get・SendRPCInternal・Return 以外を呼ぶ形に変わったとき、CalculateStats 内の通知呼び出しが1箇所でなくなったときは、Prepare の形検査がそのパッチだけを外して警告を1回出す。

効果の見込み（推定）: ホストから各参加者への確実チャネルの空 RPC（1回あたり十数バイトのヘッダと、クライアント側の受信・振り分け処理）が、状態が変わらなかった再計算の分だけ減る。戦闘中の頻度は効果の付与・解除の数に依存するため測定していないが、多いときで毎秒数百回の再計算の一部が空である（すでに同じ効果が付いている再適用や、合計が変わらないボーナス更新など）。実際の変化の直後の同期間隔1回分のあいだは、変化のない再計算の通知も従来どおり送るため、減少量はその分だけ少ない。変化のある再計算の通知と、確定・撃破・報酬・ロック解除の送信には触れていないため、参加者への状態の届き方は変わらない。
