## B0  現行仕様の確認状況

現行ゲームの数値を公開情報から整理した結果を要約する（詳細は共有フォルダの `data/current-spec-numbers.md`、調査日2026年10月1日、対象版はv1.4前後で**版の固定は未了**）。公式資料のうち取得できたのは、Steamストアページ（S2）だけである。**本付録の設計値を較正できる現行の係数は、ほぼ確認できていない。**

### 設計への影響

- **危険度と既存の難易度**：本MODの危険度（0〜5、第13章）は、既存の難易度（4段階）、Lucid Dream、Hunterとは別の軸である。重複して倍率を掛けないよう、適用順序を確認するまでは、危険度の敵の耐久補正（+10％、+20％）を仮置きとする。
- **Limboの回復の減少**：既存の限界挑戦では、回復効果が大きく減る。本書の「敵側へ一律の回復無効を与えない」方針（第7章）は、MODの危険度では維持し、既存のLimboの仕様とは独立に扱う。
- **Hunterの脅威度**：遠征の時間とともに圧力が増す仕組みが既存にある。本MODの地域三の「危険床の増加」（付録A8）や遠征の長さと、役割が重ならないかを確認する。
- **星座の仮説**：「星座の成長が敵のスケーリングに追いつかない」は、**現時点では判定保留**である。支持寄りの傍証（レベル加算型の星の存在、高レベル星が序盤向けとの発言、開発側が難易度を改善中と回答）と、反証寄りの傍証（難所のボスを初見で突破する人が多い、星は物語と報酬が主）の両方があり、数値による裏付けがない。第6章の再設計の基準は、判定を保留したまま維持する。
- **Traveler名**：Flexible Starの追加の対象にShell、Lacerta、Mist、Yubar、Vesper、Aurena、Bismuth、Nachiaの名前が挙がっている。付録A1の原型との対応は、段階0で既存の固有能力を確認してから決める（ここでは対応づけない）。
- **レベル上限**：未確定のため、第7章の経験値のペースは「間隔の目標」で書き、レベルの数を決めない方針を維持する。

## B2  計算の層と上限、検算の例

### 計算の式

最終的な能力は、おおむね次の式で与える。

> 最終値 ＝（L0＋L1）×（1＋ΣL2）×ΠL3 ×L4、その後にL5（協力の圧縮）

| 層 | 対象 | 上限 |
| --- | --- | --- |
| L1 | 固定加算 | アイテムレベルで規定 |
| L2 | 加算枠：装備特性、専門化、研究の同種％ | MOD由来の合計+120％ |
| L3 | 条件付きの独立補正（露出を含む） | 各×1.30まで、同時に有効なのは3個まで、積×1.8まで |
| L4 | 遠征内強化（既存） | 既存の仕組みに従う |

### 検算：完成と未完成の火力比

次の仮値で、完成構成と未完成構成の火力比が目標（3.0以内）に収まるかを検算する。

| 構成 | L2 | L3 | L4（遠征内） |
| --- | --- | --- | --- |
| 未完成（遠征序盤、装備更新前） | +35％ | ×1.10 | ×1.5 |
| 完成（遠征終盤、装備と専門化が揃う） | +95％（専門化25、装備65、研究5） | ×1.49（1.10×1.15×1.18） | ×2.2 |

火力比は、（1.95÷1.35）×（1.49÷1.10）×（2.2÷1.5）≒**2.87**となり、目標の3.0以内に収まる。L3の積は上限×1.8に対して1.49で余裕がある。L2が+120％を超えない範囲で、専門化・装備・研究の組合せを選ばせる。

### 検算：配分

前節の完成構成の積（1.95×1.49×2.2≒6.4）を、基礎に対する火力の倍率とみなす。対数で配分すると、各層の寄与は次のようになる。この例は配分の測り方を示すものであり、現行の強さではない。

| 由来 | 寄与（自然対数、仮） | 割合 |
| --- | --- | --- |
| 遠征内（L4） | 0.74 | 40％ |
| 装備 | 0.56 | 30％ |
| 専門化・研究 | 0.37 | 20％ |
| 既存の星座 | 0.19 | 10％ |
| 合計 | 1.86（＝ln 6.4） | 100％ |

測定では、各由来を外した時の火力の低下から寄与を求め、目標の±10ポイントに収まるかを見る。

## B3  遠征内の成長のペース

| 区間 | レベルアップ間隔の目標 |
| --- | --- |
| 序盤（開始〜25％） | 90秒以内 |
| 中盤（25〜70％） | 150秒以内 |
| 終盤（70％〜ボス） | 240秒以内 |
| 上限 | 360秒を超えない |

- 1遠征で得るレベルの数は、現行の経験値曲線の抽出後に決める。
- 間隔が目標を超える区間では、**節目報酬**で間隔の穴を補う。90秒以内の小さな満足は戦利品、素材、短い演出が担う。
- 節目報酬は、ノードを一つクリアするごとに三択を与える。構成は次のとおり。
  - Memoryの強化候補（1つ）
  - 素材（狙い系統を優先）（1つ）
  - 一時効果（その遠征のみ）（1つ）
- 三択は1遠征で2回まで引き直せる。
- 経験値の曲線は、区間ごとの目標間隔を満たすように、敵の経験値と必要経験値の比で調整する。曲線の式を先に決めず、実測から導く。

## B4  専門化のポイント

| 入手の経路 | ポイント | 回数の上限（キャラごと） |

| 標準以上の遠征の完了（ボス撃破、または第8ノード以降の安全地点からの帰還。短い遠征は守護体の撃破） | 1 | 10回（計10点） |
| 地域ボスの初回撃破 | 2 | 3地域（計6点） |
| キャラ固有の課題 | 1 | 2つ（計2点） |
| 合計 |  | 18点 |

- 遠征の完了は10回までで10点に達し、地域ボスの初回撃破（6点）と固有課題（2点）が残りを埋める。目安は、約12〜15遠征（約8〜9時間）。
- 固有課題は、そのキャラの戦い方を試す課題（例：「反撃で10体を倒す」「障壁を渡して3人の被弾を防ぐ」）。
- 研究に必要な地域印は、キャラを問わず共有する。

### エピックの救済

ボス撃破ごとに、エピックの確率は p＝min（1，0.08＋0.048×k）とする。kはエピックを得ていない連続の撃破数で、k＝19（20回目の撃破）で1.0となる。得たらkを0に戻す。

| k（未取得の撃破数） | 確率 |
| --- | --- |
| 0 | 8.0％ |
| 5 | 32.0％ |
| 10 | 56.0％ |
| 15 | 80.0％ |
| 19 | 100％（確定） |

この規則での期待値は、**約4.9回のボス撃破で1個**（試算）である。確定の初回撃破とは別に数える。協力時は個人ごとに計算する。

### 狙い系統の効果

- 出発時に選んだ系統の素材と装備の出現の重みを2倍にする。
- 地域一の主な報酬は攻勢系、地域二は共鳴系、地域三は守勢系で、狙い系統と地域の報酬が重なると効率が上がる。ただし、重ならない系統を選んでも素材は得られ、遠回りになるだけで成立する。

## B7  危険度と報酬の効率

| 危険度 | 時間の係数 | 素材の倍率 | 時間あたりの効率 |
| --- | --- | --- | --- |
| 0 | ×0.9 | ×0.8 | 0.89 |
| 1 | ×1.0 | ×1.0 | 1.00 |
| 2 | ×1.05 | ×1.2 | 1.14 |
| 3 | ×1.15 | ×1.45 | 1.26 |
| 4 | ×1.30 | ×1.75 | 1.35 |
| 5 | ×1.50 | ×2.1 | 1.40 |

- 時間あたりの効率は「素材の倍率÷時間の係数」で、**完了できた場合**の値である。失敗では、未確保の素材を失うため、成功率の低い危険度の効率は下がる。
- 隣り合う危険度の効率の差は、15％を超えないことを目標とする。差が大きいと低い危険度の反復が不利になりすぎ、小さいと挑戦の動機が弱まる。
- 危険度0は効率を下げ、反復の最適解とならないようにする。
- 成功率が70％未満の危険度は、効率が1段下の危険度を下回らないことを試験で確認する。

### アイテムレベル

アイテムレベル＝地域の帯の下限＋危険度×2。ただし、帯の上限を超えない。危険度が高いほど同じ帯の中でレベルが上がる。

## B8  協力の補正

### 圧縮の式

参加者の力 P と、部屋の目標難度の基準の力 R の比を r＝P÷R とし、圧縮後の比を r′＝clamp（r^0.5，0.7，1.4）とする。火力と耐久の数値のみに適用し、スキル、特性、専門化の効果の種類は保持する。

| r（元の比） | r′（圧縮後） |
| --- | --- |
| 0.3 | 0.70（下限） |
| 0.5 | 0.71 |
| 0.7 | 0.84 |
| 1.0 | 1.00 |
| 1.5 | 1.22 |
| 2.0 | 1.40（上限） |
| 3.0 | 1.40（上限） |

例：基準の力の部屋に、r＝2.0の参加者とr＝0.5の参加者が入る場合、差は4.0倍から1.97倍（1.40÷0.71）に縮まる。育てた参加者は1.4倍まで強いままで、初心者は0.71倍の力で参加できる。

### 人数による敵の補正

| 人数 | 敵のHP | 敵の数 | 総脅威（HP×数） | 人数比 |
| --- | --- | --- | --- | --- |
| 1 | ×1.0 | ×1.0 | 1.00 | 1 |
| 2 | ×1.6 | ×1.25 | 2.00 | 2 |
| 3 | ×2.2 | ×1.5 | 3.30 | 3 |
| 4 | ×2.8 | ×1.75 | 4.90 | 4 |

人数が増えるほど総脅威は人数比をやや上回る。協力の相互作用（共鳴、状態、蘇生）で人数比以上に戦力が増えることを前提にした設計値で、試験で較正する。

## B9  較正の手順

現行値の抽出後、次の順で較正する。一度に一つの変数を変える。

1. **基準線**：標準構成の撃破時間（第13章の表）を、現行の敵のHPと火力から求める。
2. **層と配分**：現行の星座、Memory、遠征内レベルの強さを層に割り当て、配分の目標（40／30／20／10）に対して装備と専門化の寄与の目標値を決める。
3. **成長のペース**：現行の経験値曲線を、区間ごとの間隔の目標と比べる。
4. **経済**：収入の範囲を、危険度1の標準遠征の実測で確かめ、費用を調整する。
5. **協力**：基準の力 R を、地域と危険度ごとに、標準構成の力から定める。

比較の基準は、第19章と付録Dの指標である。

### 実機での計測（逆コンパイルが難しい場合の代替）

1. 固定した構成（通常構成1つ、完成構成1つ）で、各ワールドの標準敵とボスの「撃破時間」と「被弾許容量」を、難易度ごとに記録する。
2. 同じ構成で、星座なし、序盤の星のみ、高レベルの星ありの3条件を比べる。
3. 同じワールドの敵のHPを、デバッグ表示または与ダメージの合計から逆算する。
4. 結果を次の式に入れ、頭打ちが起きるワールドとレベルを特定する。

### 星座の仮説の検証式

ワールド w、難易度 d、Heroのレベル L ごとに、次を測る。

- 敵の耐久：E(w,d)＝標準敵のHP÷1秒あたりの実効ダメージ（通常構成）
- 星座の寄与：S(L)＝星座由来の能力値の増分が実効火力・実効耐久に与える割合（星座なしとの対比）
- 判定：S(L)の増分が、E(w,d)の増分より遅れ始める w（または L）があるか

「追いつかない」とは、通常構成でワールドが進むほど撃破時間と被弾許容量が悪化し、かつ S(L) の増分が頭打ちになる状態を指す。単に難しいことや、特定のビルドが強いことを指さない。この式は、第6章の再設計の基準（星の限界価値、停滞する区間）の測り方と対応する。
