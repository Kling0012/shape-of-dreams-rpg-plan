# Dreamforge RPG 開発計画

次に作るものを、実装の前に単独のコミットとしてここへ記す。完了した版は「完了」に移す。

## 方針（2026-10-01 改定）

Dreamforge は単独のゲームではなく **Shape of Dreams のMOD**。新しい要素は、本体の仕組み（Memory・Essence・属性・旅人の固有能力・祭壇・商人・ハンター・Limbo の深度）に乗り、それを強めるものを優先する。各項目に、土台にする本体のAPIを明記する。

## 次：v1.4「経済の橋渡し」

[シナジー再評価](dreamforge-synergy-review.md) の第4弾（最後）。MOD独自の通貨・恒久強化を本体の経済に寄せる。

1. **ドリームダスト → 欠片**：確保地点で、ラン内のドリームダストを欠片に換えられる（クライアント→ホストへ依頼し、ホストが `DewPlayer.SpendDreamDust` で支払う）。換算率は要調整。
2. **出来事の支払いをゴールドに**：夢の商人はラン内のゴールド（ホストが `SpendGold`、本体の `GetAdjustedGoldAmount_Cost` を通す）で買う。祈りの泉・賭けの杯もゴールド／ダスト建てを検討。
3. **ラン中の遺物の分解はドリームダストを返す**（`PickupManager.DropDreamDust`、本体の星座「分解ボーナス」に乗る）。拠点（遠征の外）では従来どおり欠片。
4. **夢の工房の縮小**：大きな鞄・広い保管庫・依頼の引き直しだけ残し、遺失物の灯・残響の増幅・契約の目利きは旅人の刻印や本体の仕組みへ移す（解放済みのものは欠片で返す）。
5. **試験**：換算・支払いの検証（ホストのみが通貨を動かす）、工房の移行と返金、保存の往復。
6. **実機確認**：v1.0〜v1.3 の本体連動（属性付与・4発目・MirageSkin・呪い・Limbo）を実際に遊んで確認。

## その後の候補（シナジー再評価の順番）


- 悪夢の契約を本体の呪い（`CurseStatusEffect`）・Evil の明晰夢と結び付ける
- 夢の商人の支払いをラン内のゴールドに（ホスト経由で `SpendGold`）、遺物の分解でドリームダスト
- 開始深度と本体の Limbo 深度の表示・係数をそろえる

- 悪夢化エリートの専用接頭効果（分裂・吸魂など、ゲーム側の挙動確認が要るもの）
- キャラ別の固有課題（計画書 第8章）と専用の刻印
- 依頼の掲示板（遠征前に3つから選ぶ・引き直し）
