# Dreamforge RPG 開発計画

次に作るものを、実装の前に単独のコミットとしてここへ記す。完了した版は「完了」に移す。

## 方針（2026-10-01 改定）

Dreamforge は単独のゲームではなく **Shape of Dreams のMOD**。新しい要素は、本体の仕組み（Memory・Essence・属性・旅人の固有能力・祭壇・商人・ハンター・Limbo の深度）に乗り、それを強めるものを優先する。各項目に、土台にする本体のAPIを明記する。

## 次：v1.2「旅人の刻印」

[シナジー再評価](dreamforge-synergy-review.md) の第2弾。本体の星座と重なっていた汎用の星図を、**旅人ごとのキットに効く刻印**へ置き換える。

1. **旅人ごとの刻印ツリー**（9人）：各旅人に小ノード4つ（各3段）と到達刻印1つ。ノードはその旅人のキットに効くものだけにする。
   - 例：Vesper／Lacerta＝4発目の位置を進める（`everyFourAttackStartIndexFlat`）・火の増幅、Cetus＝冷気の増幅・シールド、Yubar＝Memory Haste・光、空殻＝闇・会心ダメージ、Mist＝回避と攻撃速度、Nachia＝光・魔力、Aurena＝最大HP・光、Bismuth＝4属性の増幅。
   - 到達刻印は既存の固有効果を旅人に合わせて割り当てる（例：Lacerta＝火種、Cetus＝霜、Mist＝回避の残響、Yubar＝終の昂り）。
   - 本体以外の旅人（他MODのキャラ）には従来の汎用ツリーを残す。
2. **熟練度は刻印の解放条件に**：汎用の能力%（攻撃力・魔力・最大HP+1%/段）をやめ、到達刻印は熟練度3以上で選べる。
3. **新しい能力値**：通常攻撃の射程%（`attackRangePercentage`）、4発目の位置（`everyFourAttackStartIndexFlat`、上限2）。
4. **保存の移行**：本体の旅人で汎用ツリーに振っていたポイントは自動で戻る（ノードIDが変わるため）。
5. **試験**：9人分のツリーの整合、到達刻印の条件（6pt・熟練度3）、新しい能力値の変換、移行。

## その後の候補（シナジー再評価の順番）

- v1.3 呪いの契約と系統の統一（破壊・生命・想像）、セットを旅人・属性テーマへ
- v1.4 経済の橋渡し（ドリームダスト→欠片、出来事の支払いをゴールドに、工房の縮小）

- 悪夢の契約を本体の呪い（`CurseStatusEffect`）・Evil の明晰夢と結び付ける
- 夢の商人の支払いをラン内のゴールドに（ホスト経由で `SpendGold`）、遺物の分解でドリームダスト
- 開始深度と本体の Limbo 深度の表示・係数をそろえる

- 悪夢化エリートの専用接頭効果（分裂・吸魂など、ゲーム側の挙動確認が要るもの）
- キャラ別の固有課題（計画書 第8章）と専用の刻印
- 依頼の掲示板（遠征前に3つから選ぶ・引き直し）
