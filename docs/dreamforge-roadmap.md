## 次：v0.8「夢の工房」

狙い：余った欠片・調律石の使い道（長期の目標）と、遠征前の小さな判断を増やす。参考：Hades の「鏡」（アカウント共通の恒久強化）、Slay the Spire の事前選択。

1. **夢の工房（研究）**：拠点で欠片と調律石を払って、アカウント共通の恒久強化を解放する（計画書 第11章「研究」を簡略化）。
   - 大きな鞄：未確保の鞄の上限 +5（3段階）
   - 広い保管庫：保管庫の上限 +20（3段階）
   - 依頼の引き直し：遠征ごとに依頼を1つ引き直せる回数 +1（2段階）
   - 遺失物の灯：遺失物の回収に必要な戦闘部屋 3 → 2（1段階）
   - 残響の増幅：全滅時に持ち帰る欠片 25% → 35% → 45%（2段階）
   - 契約の目利き：悪夢の契約の選択肢 3 → 4（1段階）
   - 費用は段階ごとに増える。強さそのもの（攻撃力など）は上げず、遊びやすさと選択肢を増やす。
2. **依頼の引き直し**：HUD／記録から依頼を1つ選んで引き直す（工房の段階に応じた回数）。
3. **画面**：メニューに「工房」タブ。
4. **試験**：段階・費用・上限、各効果（鞄・保管庫・回収部屋数・残響・契約数・引き直し）、保存の往復。
