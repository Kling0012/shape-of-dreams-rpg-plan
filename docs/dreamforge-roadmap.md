# Dreamforge RPG 開発計画

次に作るものを、実装の前に単独のコミットとしてここへ記す。完了した版は「完了」に移す。

## 方針（2026-10-01 改定）

Dreamforge は単独のゲームではなく **Shape of Dreams のMOD**。新しい要素は、本体の仕組み（Memory・Essence・属性・旅人の固有能力・祭壇・商人・ハンター・Limbo の深度）に乗り、それを強めるものを優先する。各項目に、土台にする本体のAPIを明記する。

## 次：v1.3「呪いの契約と系統の統一」

[シナジー再評価](dreamforge-synergy-review.md) の第3弾。

1. **契約の代償を本体の呪いに**：悪夢の契約を結ぶと、本体の呪い（`CurseStatusEffect`、Hatred の祭壇と同じもの）がランダムに1つ付く。強度（Mild／Potent／Powerful）は契約の見返りの大きさに応じる。呪いの見た目・効果・解除の依頼（キル数など）は本体のものがそのまま動く。
   - MOD独自の能力値の代償（最大HP減・防御減など）は廃止。見返り（ドロップ率・幸運・欠片・経験・狂乱の攻撃力など）は今までどおり次の確保まで。
   - 協力時は、契約したプレイヤーのキャラだけに呪いが付く（クライアント→ホストの通知）。
2. **系統を本体の星座系統に統一**：攻勢・守勢・共鳴 → **破壊・生命・想像**（本体の Destruction／Life／Imagination）。狙い系統・系統セット・図鑑の表示を揃える。内部IDは変えないので保存はそのまま。
3. **セット遺物のテーマ**：《潮鳴りの装い》を冷気と回避（Cetus・Mist 向け）、《灯守の誓い》を光と回復（Nachia・Aurena 向け）に寄せ、3点の固有効果を属性系へ。
4. **試験**：契約の呪いの強度、代償が能力値に出ないこと、系統名、セットの新しい効果。
