# Dreamforge RPG 開発計画

次に作るものを、実装の前に単独のコミットとしてここへ記す。完了した版は「完了」に移す。

## 方針（2026-10-01 改定）

Dreamforge は単独のゲームではなく **Shape of Dreams のMOD**。新しい要素は、本体の仕組み（Memory・Essence・属性・旅人の固有能力・祭壇・商人・ハンター・Limbo の深度）に乗り、それを強めるものを優先する。各項目に、土台にする本体のAPIを明記する。

## 次：v1.5「経済の橋渡しと仕上げ」

実機確認は利用者のテストプレイで行う（2026-10-02 指示）。こちらは実装に集中する。

1. **本体の通貨を使う取引**（ホストだけが通貨を動かす：`DewPlayer.SpendGold/SpendDreamDust/EarnDreamDust`）
   - クライアント→ホストへ「支払い・受け取り」を依頼し、ホストが残高を確かめて実行し、結果を返す。成功したときだけクライアントの遺物側の処理を確定する。
   - **夢の商人はゴールド払い**（本体の `GetAdjustedGoldAmount_Cost` で難易度補正）。
   - **確保地点でドリームダスト→欠片**（ダスト100で欠片10）。
   - **遠征中の未確保の遺物を分解するとドリームダスト**（本体の Memory/Essence の分解と同じ感覚）。
2. **夢の工房の縮小**：遺失物の灯・残響の増幅・契約の目利きを廃止し、解放済みなら費用を欠片・調律石で返す。鞄・保管庫・依頼の引き直しは残す。
3. **表示の仕上げ**：HUD の表示量を設定で選べる（詳しく／簡潔／なし）。
4. **試験**：取引の確定は成功時だけ・二重確定なし、ダスト換算、分解のダスト量、工房の返金。

## その後の候補（シナジー再評価の順番）



- 悪夢の契約を本体の呪い（`CurseStatusEffect`）・Evil の明晰夢と結び付ける
- 夢の商人の支払いをラン内のゴールドに（ホスト経由で `SpendGold`）、遺物の分解でドリームダスト
- 開始深度と本体の Limbo 深度の表示・係数をそろえる

- 悪夢化エリートの専用接頭効果（分裂・吸魂など、ゲーム側の挙動確認が要るもの）
- キャラ別の固有課題（計画書 第8章）と専用の刻印
- 依頼の掲示板（遠征前に3つから選ぶ・引き直し）
