# Dreamforge RPG（日本語の説明）

**日本語** | [English](README.en.md) | [中文](README.zh.md)

Shape of Dreams 用の MOD「Dreamforge RPG」の説明です。Steam ワークショップの説明文と同じ内容です。

すべての遠征を長いRPGの旅の一部にするMODです。持ち帰れる装備「遺物」、ゾーンごとの「確保するか、深く潜るか」の決断、旅人ごとの星図、鍛冶、長く遊ぶための目標を加えます。協力プレイにも対応しています。

## 不具合の報告
このMODは、すべてAIが作成しています。テストプレイは行っていません。プレイヤーの皆さんからの積極的な報告を歓迎します。
不具合の報告と要望、パッチノート、英語と中国語の説明は、[GitHub のページ](https://github.com/Kling0012/dreamforge-rpg)にまとめています。

## 導入
- [Steam ワークショップ](https://steamcommunity.com/sharedfiles/filedetails/?id=3822274988)で Dreamforge RPG を購読します。Steam がダウンロードと更新を行います。
- ゲームを起動し、MOD の管理画面で Dreamforge RPG を有効にします。
- 更新後はゲームを再起動します。セーブデータは引き継がれます。

## 遺物
- 敵を倒すと、プレイヤーごとに別々の遺物が落ちます。部位は6つ、レア度は5段階で、遺物には1つずつ絵が付いています。固有品とセットもあります。
- レアは固有効果を1つ、エピックは2つ持ちます。固有効果は、Q・W・Eの使い分け、会心、スタン、超過回復、エッセンスの品質など、本体の仕組みに反応します。
- 固有品は、装着して敵を倒すほど目覚めます。覚醒は3段階です。

## 確保か、深く潜るか
- 新しいゾーンに着くたびに、拾った物を「確保する」で保管庫に入れるか、「深く潜る」で戦利品を増やすかを選びます。1段潜るごとに、受けるダメージが6%増えます。
- 確保地点には「夢の出来事」や、呪いと引き換えに見返りを得る「悪夢の契約」が現れることがあります。
- 全滅すると、持ち帰っていない遺物は遺失物になります。次の遠征で戦闘部屋を3つ突破すると、一番良い物を1つ取り戻せます。

## 敵
- 敵は深さに合わせて強くなり、強い装備で潜るほど、特別な性質を持つ悪夢の敵が増えます。
- 「夢の圧」は、人数ではなく参加者の成長の平均から、敵のHP・与ダメージ・数を強化します。ボスの数は増えません。
- 本体の敵をもとにした「夢の変種」は、見た目と能力が変わり、良い戦利品を落とします。

## 成長
- 旅人ごとに星図があり、星の経験とポイントも旅人ごとに別です。記憶ごとのルートの星は、その記憶を強くします。振り直しは無料です。
- 鍛冶では強化・再調律・分解・合成・製作ができます。工房では鞄や保管庫の拡張などを解放できます。
- 遠征ごとの依頼、日替わりの「今日の夢」、報酬つきの偉業、旅人の熟練度があります。

## 軽さ
設定でゲーム全体を軽くできます。裏にあるときのFPS上限や、描画の軽量化を選べます。

## 操作
- F6: Dreamforge のメニュー
- F7: 確保する　F8: 深く潜る
- キー・言語・表示の大きさは、MOD設定で変えられます。言語は日本語・英語・中国語（簡体字）から選べます（中国語の未訳の部分は英語で表示されます）。

## マルチプレイ
参加者全員が同じ版のMODを入れてください。能力の反映はホストが行います。保存と戦利品はプレイヤーごとに別々です。

このMODはゲームプレイを変更します。セーブファイル: `<persistentDataPath>/QuickSave/Mods/DreamforgeRPG/profile.json`
