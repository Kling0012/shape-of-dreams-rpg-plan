### 新機能 / New features
- 動的難易度をやさしくしました。敵が強くなる量を小さくし、世界ごとに上限を設けました。苦戦しているときは、これまでより大きく敵の体力が下がります。動的難易度で敵の攻撃力が変わることはなくなりました。 / Dynamic difficulty is now gentler: enemies scale up less, the increase is capped per world, and enemy HP drops much more when you are struggling. Dynamic difficulty no longer changes enemy damage.
- 画面左上のまとめ表示に、動的難易度で敵の体力と報酬がどれだけ変わっているかを出すようにしました。 / The top-left HUD summary now shows how much dynamic difficulty changes enemy HP and rewards.
